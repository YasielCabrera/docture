**Breaking (0.x):** conversion JSON is now `schemaVersion: 2`, described by the new `docture-document-v2.schema.json`. The published version 1 schema is frozen and unchanged. Version 2 adds the `page-header` and `page-footer` element kinds, an optional `lineIds` list of canonical `p<page>-line-<n>` IDs on each provenance segment, `TableElement.spans` for merged cells, `ElementProvenance.continuations` for a table or paragraph that continues onto later pages, and `TableElement.rowProvenance` with one segment per row. `ConvertedPage.content` holds every element that starts on the page, including the part of it on later pages. `DocumentElement` gains the two furniture kinds, so an exhaustive `switch` over `element.kind` needs two new cases, and `LayoutElementRole` excludes them. New exports: `parseDoctureDocument()` validates saved version 1 or version 2 JSON and returns a version 2 document with dotted-path issues; `sourceLines()` and `isLineSourceId()` enumerate and recognise canonical line IDs; and the types `ProvenanceSegment`, `SourceLine`, `LineSourceId`, `PageHeaderElement`, `PageFooterElement`, `FurnitureEvidence` and `DoctureDocumentParse`.
