"docture": minor

Detect merged table cells and multi-row headers. When table rows differ in cell count, the rows with the most cells set the column bands, and shorter rows join the table when each cell falls in a band, so totals and sparse rows stay in their table. A label that covers more than half of each of several empty columns becomes a merged cell in the new `TableElement.spans` (`TableCellSpan`), and `headerRows` counts the header rows such a label proves. HTML writes `colspan` and `rowspan`. Markdown flattens header rows into one row, as in `| Item | Quarters / Q1 | Quarters / Q2 |`, and leaves covered body cells blank. TXT keeps the source lines. Row spans need a cell box that covers each spanned row line, which OCR or synthetic geometry can provide; an empty cell never makes one. Tables whose rows all have the same cell count convert as before, except that a row starting more than three row spacings below the row above, such as a page footer, no longer joins the table. `parseDoctureDocument()` rejects saved tables whose spans overlap, leave the grid, cross the header rows, or cover non-empty cells, and a layout analyzer group that would produce such a table is ignored.
