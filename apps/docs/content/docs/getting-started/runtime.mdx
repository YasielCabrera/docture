Use this page to check that a deployment target can run the Docture components you selected. To choose between the portable `docture` entry and `docture/node` for your sources, see [Select a runtime entry](/docs/getting-started/sources#select-a-runtime-entry).

## Use Node.js 22 or newer

The packages require Node.js 22 or newer. Node 22.18 or newer loads erasable TypeScript CLI configuration directly. Earlier Node 22 releases require `--experimental-strip-types` or compiled JavaScript.

The complete PDF tutorials and installation recipes use Node.js 22.18 or newer.
Optional engines can require a higher version than the core package; for example,
the supported PDF.js floor requires Node.js 22.13 or newer. Check the selected engine
before deploying an application on an earlier Node 22 release.

## Check each component

A portable root does not make every adapter browser-safe. Check the row for each component you use:

| Component | Deployment constraint |
| --- | --- |
| Core and retrieval chunks | Portable runtime entries; no Node globals required at runtime |
| Local file sources and HTTP service | Node-only entries |
| PDF, OCR, and raster adapters | Check the selected adapter's engine, native bindings, WASM, workers, and model assets |
| Evaluation root | Portable scoring and result types; storage and reporter entries have Node dependencies |
| Synthetic root | Portable value models and templates; renderers and corpus writing require selected engines |
| React synthetic templates | `react` and `@react-pdf/renderer`; no browser |
| HTML synthetic templates | `playwright-core` and a separately installed Chromium build |

[Package and engine requirements](/docs/getting-started/reference/packages) lists the engine versions and native dependencies of each entry.

## Type-check browser builds

Browser TypeScript projects that use the schema helpers currently need `skipLibCheck: true`. The upstream declarations of those helpers reference the Node `Buffer` global in unrelated types. The core runtime checks run without `Buffer` or `process`, so this limitation adds no runtime Node dependency.
