Docture extracts typed data, converts documents to grounded content, evaluates processors, and generates labeled synthetic documents.

| Goal | Start with |
| --- | --- |
| Extract fields into your schema | [Extraction quick start](/docs/extraction/quick-start) |
| Convert a PDF to text, Markdown, HTML, or JSON | [Conversion quick start](/docs/conversion/quick-start) |
| Measure accuracy and gate regressions | [Evaluation quick start](/docs/evaluation/quick-start) |
| Generate documents with known field values and boxes | [Synthetic data quick start](/docs/synthetic/quick-start) |
| Work from a terminal or agent host | [CLI and services](/docs/cli) |

The four packages are `docture`, `@docture/cli`, `@docture/eval`, and `@docture/synthetic`. The core root has no PDF, OCR, or model engine. Install the optional peers required by the entries you use.

Read [packages and installation](/docs/getting-started/installation), then [how Docture works](/docs/getting-started/how-it-works).
