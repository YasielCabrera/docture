`docture/node` adds local file access to core. It exports the core API with Node source defaults for `Extractor`, `DocumentConverter`, `Process`, `createExtractor`, `createCheckedExtractor` and `createDocumentConverter`, so those accept file paths and `file:` URLs. [Select a runtime entry](/docs/getting-started/sources#select-a-runtime-entry) explains when to use this entry, and [Document sources](/docs/getting-started/sources) shows every source form in use.

## Read local files

### `resolveNodeSource`

Resolves any `DocumentSource` to bytes, including local paths and `file:` URLs.

```ts
const resolveNodeSource: SourceResolver
// (source: DocumentSource, signal?: AbortSignal) => Promise<RawDocument>
```

Returns a `RawDocument`. For a local file, `bytes` holds the file contents and `fileName` its base name; the media type comes from the byte signature, then the extension. Other sources resolve as with the portable [`resolveSource`](/docs/getting-started/reference/documents#resolvesource). `resolveSource` from `docture/node` is an alias of `resolveNodeSource`.

Throws `UnsupportedSourceError` when a file cannot be read, with the file-system error as `cause` and a fix for missing files, directories, and denied permissions. It also throws `UnsupportedSourceError` for empty input, unsupported protocols, failed HTTP requests, and a `LoadedSource`. An aborted `signal` rejects with its reason.

```ts check
import { resolveNodeSource, DocumentConverter } from "docture/node";
import { DocumentLoaderPdfJs } from "docture/loaders/pdfjs";

async function convertLocalFile(path: string) {
  const converter = new DocumentConverter({ loaders: [new DocumentLoaderPdfJs()] });
  try {
    return await converter.convert(await resolveNodeSource(path), { format: "text" });
  } finally {
    await converter.dispose();
  }
}
```

## Runtime boundaries

The entry is available only under Node's export condition. Through the portable root, local paths and file URLs raise `UnsupportedSourceError`.

Node paths resolve from the process working directory. File URLs retain platform URL decoding. Importing `docture/node` registers no global resolver. To read local files through a constructor imported from the root, pass `sourceResolver: resolveNodeSource` to it.
