Each published package keeps its own changelog. Read the changelog for every package you
upgrade. Minor 0.x releases can contain breaking changes, and each breaking entry says
what to change.

- [`docture` changelog](https://github.com/YasielCabrera/docture/blob/main/packages/docture/CHANGELOG.md)
  covers core, model integrations, adapters, evaluation, and testing. It also keeps the
  release history of the packages that were merged into `docture`.
- [`@docture/cli` changelog](https://github.com/YasielCabrera/docture/blob/main/packages/cli/CHANGELOG.md)
  covers the `docture` command.

To find the subpath that replaces a removed scoped package, see the
[migration guide](/docs/guides/migration).
