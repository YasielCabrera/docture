The `docture` facade re-exports every public export from `@docture/core` and
`@docture/llm`. The adapter, evaluation, testing, and CLI packages use their own package
imports.

```ts
import { Extractor, contract, llm, vision } from "docture";
import { DocumentLoaderPdfJs } from "@docture/loader-pdfjs";
```

Import supported symbols from a package root. Files under `src` and `dist` are internal.
