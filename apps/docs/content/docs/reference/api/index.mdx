The `docture` root exports core only. Model components, adapters, and testing use explicit
`docture` subpaths. `@docture/cli`, `@docture/eval`, and `@docture/synthetic` are the other
published packages.

```ts
import { contract } from "docture";
import { Extractor } from "docture/node";
import { llm } from "docture/llm/text";
import { vision } from "docture/llm/vision";
import { DocumentLoaderPdfJs } from "docture/loaders/pdfjs";
```

Import supported symbols from the public entries in the [package reference](/docs/reference/packages).
Files under `src` and `dist` are internal.
