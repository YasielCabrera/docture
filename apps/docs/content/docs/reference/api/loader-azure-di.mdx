---
title: Azure Read loader
description: Read PDF and image text through a fetch-only Azure Document Intelligence adapter.
---

`docture/loaders/azure-di` exports `DocumentLoaderAzureRead`, `DocumentLoaderAzureReadOptions`, `AzureReadAuthentication` and `AzureReadError`. The adapter uses built-in fetch, API `2024-11-30`, `prebuilt-read` and UTF-16 span indexing. No SDK peer is required. Import and construction make no service request.

Options require an `endpoint` and `auth`. Key authentication uses `{ kind: "key", key }`; bearer authentication uses `{ kind: "bearer", token }`. `fetch` allows transport injection. `timeoutMs` is a finite total deadline with a default of 120000 ms. `pollIntervalMs` defaults to 1000 ms. Caller cancellation covers requests, response bodies and polling delays. Credentials stay in headers and do not enter logs or metadata. Operation links must remain on the configured origin, and redirects are rejected.

The tested MIME types are PDF, PNG, JPEG and TIFF. The service receives selected original page numbers through `LoadRequest.pages`, and the returned pages keep those numbers. Office formats are outside this adapter's contract. `images` is false; compose a rasterizer with `withRasterizer` when a vision strategy needs images.

Inch polygons scale by 72 into top-left PDF points. Pixel polygons need a caller-confirmed `imageDpi`; an image's pixel dimensions alone do not establish physical size. Rotated polygons become axis-aligned boxes. Words join lines through source spans and retain confidence. Unknown units or missing scale produce zero dimensions and text-only pages with diagnostics. Missing word geometry also keeps text without fabricated line boxes. Runtime feature checks remain authoritative for actual geometry.

HTTP, service-state and result-contract failures raise `AzureReadError` with `LOAD_FAILED`. The total deadline raises `TIMEOUT`; caller abort keeps its reason. Metadata records the API/model, original page units and geometry diagnostics without endpoint, credentials or source text.

`apps/examples/20-input-loaders/azure.ts` runs against a deterministic local mock server. No live Azure check was run.
