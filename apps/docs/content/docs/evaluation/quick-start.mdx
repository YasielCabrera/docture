This program runs one processor against one expected answer and checks its F1. No model or document engine is required.

## Install

```sh
npm install @docture/eval docture zod
npm install --save-dev tsx
```

## Run a case

Save as `evaluate.mts`:

```ts check
import { defineEval, exact, gate, inMemoryDataset } from "@docture/eval";
import { runEval } from "@docture/eval/runner";
import { renderScoreboard } from "@docture/eval/reporters/terminal";
import { z } from "zod";

const schema = z.object({ title: z.string(), count: z.number() });
const spec = defineEval(schema, { strings: exact() });
const dataset = inMemoryDataset("inventory", [{
	id: "one",
	documents: [],
	expected: { title: "Screws", count: 12 },
}]);
const result = await runEval({
	dataset,
	spec,
	experiments: {
		parser: {
			id: "parser",
			async extract() {
				return { raw: { title: "Screws", count: 12 } };
			},
		},
	},
});
console.log(renderScoreboard(result));
console.log(gate(result, { thresholds: [{ metric: "f1", min: 1 }] }).pass);
```

```sh
npx tsx evaluate.mts
```

The scoreboard reports F1 `1`, and the last line is `true`. Change `count` in the processor answer to `11` to produce a mismatch and fail the threshold.
