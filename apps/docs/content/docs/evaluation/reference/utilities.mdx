Import JSON, fingerprint, path, and slice helpers from `@docture/eval`. Reporters and custom metrics use them to read results.

## `@docture/eval`

### `toJsonValue`

```ts
toJsonValue(value: unknown): JsonValue
```

Returns [`JsonValue`](/docs/evaluation/reference/types#jsonvalue).

Convert any value to its JSON form the way `JSON.stringify` would, so a result holds exactly what a saved copy holds. `undefined`, functions, symbols and non-finite numbers become `null`; dates become ISO strings.

### `canonicalJson`

```ts
canonicalJson(value: unknown): string
```

`JSON.stringify` with object keys sorted, so equal values always produce equal text.

### `fingerprintOf`

```ts
fingerprintOf(value: unknown): string
```

A stable 64-bit FNV-1a fingerprint of a value's canonical JSON, as 16 hex digits. Equal values hash equally across processes and platforms, so specs, datasets and experiment configs can be compared between saved runs.

### `compareCodeUnits`

```ts
compareCodeUnits(a: string, b: string): number
```

Order strings by UTF-16 code unit, the same on every host. Use it wherever order reaches a fingerprint, a seed or written output; `localeCompare` depends on the host locale.

### `formatPath`

```ts
formatPath(segments: readonly PathSegment[]): string
```

Takes [`PathSegment`](/docs/evaluation/reference/utilities#pathsegment).

Format path segments as a concrete path: `formatPath(["lineItems", 3, "amount"])` is `lineItems[3].amount`.

### `patternOf`

```ts
patternOf(path: string): string
```

Turn a concrete path into its pattern: `lineItems[3].amount` becomes `lineItems[].amount`. Returns the text unchanged when it does not parse.

### `sliceValues`

```ts
sliceValues<C>(slices: Readonly<Record<string, SliceSpec<C>>>, item: C): Record<string, TagValue>
```

Takes [`SliceSpec`](/docs/evaluation/reference/utilities#slicespec). Returns [`TagValue`](/docs/evaluation/reference/types#tagvalue).

Evaluate slices for one item. Absent values are left out.

## Types

### `PathSegment`

One step of a path: an object key or an array index.

```ts check
type PathSegment = string | number;
```

### `SliceMap`

Named slices over cases, the type of the `slices` option in [`RunEvalOptions`](/docs/evaluation/reference/runner#runevaloptions) and [`EvalConfig`](/docs/evaluation/reference/config#evalconfig).

```ts
type SliceMap<T = unknown> = Readonly<Record<string, SliceSpec<EvalCase<T>>>>;
```

### `SliceSpec`

How to read a slice: a path into the case such as `tags.rendition`, or a function.

```ts
type SliceSpec<C> = string | ((item: C) => SliceValue);
```

### `SliceValue`

A value a slice function may return. `null` and `undefined` leave the case out of the slice.

```ts
type SliceValue = TagValue | null | undefined;
```
