Import the JUnit reporter from `@docture/eval/reporters/junit`. [Gate evaluation regressions in CI](/docs/evaluation/ci) shows where JUnit output fits.

## `@docture/eval/reporters/junit`

This entry imports Node.js file APIs, so it runs only in Node.js. `junitReporter` writes the finished result to `out`.

### `renderJunit`

```ts
renderJunit(result: EvalResult, options?: JunitOptions): string
```

Takes [`EvalResult`](/docs/evaluation/reference/types#evalresult) and [`JunitOptions`](/docs/evaluation/reference/reporters-junit#junitoptions).

The result as JUnit XML: one suite per experiment, one test case per case and epoch, and the gate checks as their own suite. Throws `TypeError` when `threshold` is not a finite number in [0, 1].

### `escapeXml`

```ts
escapeXml(text: string): string
```

Escape text for an XML attribute or element, dropping characters XML 1.0 cannot carry.

### `junitReporter`

```ts
junitReporter(options: JunitReporterOptions): Reporter
```

Takes [`JunitReporterOptions`](/docs/evaluation/reference/reporters-junit#junitreporteroptions). Returns [`Reporter`](/docs/evaluation/reference/core#reporter).

Write the result as JUnit XML for CI test views. The factory checks `threshold` when it is called, so an invalid threshold throws `TypeError` before any run starts.

## Types

### `JunitOptions`

Options for `renderJunit`.

{/* options: JunitOptions */}
| Option | Type | Description |
| --- | --- | --- |
| `threshold` | `number` | A scored case fails when its F1 is below this. Default: it fails unless every leaf and assertion passed. |

### `JunitReporterOptions`

Options for `junitReporter`.

{/* options: JunitReporterOptions */}
| Option | Type | Description |
| --- | --- | --- |
| `out` | `string` | Required. File to write. |
| `threshold` | `number` | A scored case fails when its F1 is below this. Default: it fails unless every leaf and assertion passed. |
