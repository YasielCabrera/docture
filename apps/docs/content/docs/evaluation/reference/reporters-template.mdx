Import the template reporter from `@docture/eval/reporters/template` to write any text format. [Generate and customize evaluation reports](/docs/evaluation/reports) shows reporters in use.

## `@docture/eval/reporters/template`

This entry imports Node.js file APIs, so it runs only in Node.js. `templateReporter` writes the finished result to `out`.

### `renderTemplate`

```ts
renderTemplate(result: EvalResult, render: TemplateRender): string
```

Takes [`EvalResult`](/docs/evaluation/reference/types#evalresult) and [`TemplateRender`](/docs/evaluation/reference/reporters-template#templaterender).

Render a result through a custom template function.

### `templateReporter`

```ts
templateReporter(options: TemplateReporterOptions): Reporter
```

Takes [`TemplateReporterOptions`](/docs/evaluation/reference/reporters-template#templatereporteroptions). Returns [`Reporter`](/docs/evaluation/reference/core#reporter).

Write whatever a render function returns, such as a Slack summary or a custom text file.

## Types

### `TemplateHelpers`

What a template's render function receives besides the result.

```ts
type TemplateHelpers = ReturnType<typeof templateHelpers>;
```

### `TemplateRender`

A render function for any text format.

```ts
type TemplateRender = (result: EvalResult, helpers: TemplateHelpers) => string;
```

### `TemplateReporterOptions`

Options for `templateReporter`.

{/* options: TemplateReporterOptions */}
| Option | Type | Description |
| --- | --- | --- |
| `out` | `string` | Required. File to write. |
| `render` | `TemplateRender` | Required. Returns the file text from the result and the template helpers. |
| `id` | `string` | Reporter id. Default `template`. |

This entry also exports [`TableView`](/docs/evaluation/reference/reporters-markdown#tableview).
