title: Evaluation API reference
description: Lookup for all @docture/eval entries, result formats, and reporter APIs.
---

Install `@docture/eval` beside its required `docture` peer. The root is portable and engine-free. Node file access lives in `@docture/eval/node`. Only the judge needs the optional `ai` peer.

See the [evaluation quick start](/docs/evaluation/quick-start) for the complete pipeline. Specs expose `validate`, `score`, `scoreAsync` and `explain`. Metrics use null for empty denominators. Saved results use format `docture-eval-result`, version 1, described by `@docture/eval/result-v1.schema.json`.
