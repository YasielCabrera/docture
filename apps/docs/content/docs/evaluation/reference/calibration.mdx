Import confidence calibration from `@docture/eval/calibration`. [Calibrate evaluation field confidence](/docs/evaluation/calibration) shows it in use.

## `@docture/eval/calibration`

Defaults: 10 bins, grouping by `pattern`, target precision 0.99 and minimum support 5. Auto-accept requires a one-sided 95% Clopper-Pearson lower bound.

### `calibrate`

```ts
calibrate(result: EvalResult, options?: CalibrationOptions): CalibrationReport
```

Takes [`EvalResult`](/docs/evaluation/reference/types#evalresult) and [`CalibrationOptions`](/docs/evaluation/reference/calibration#calibrationoptions). Returns [`CalibrationReport`](/docs/evaluation/reference/types#calibrationreport).

Calibrate exact confidence counts. Auto-accept requires a one-sided 95% Clopper-Pearson lower bound. An errored case's omissions count toward `groundTruth` overall and in pattern, field-type and segment groups; `by: "path"` groups count only scored cases, because an errored case has no concrete paths.

### `mergeCalibration`

```ts
mergeCalibration(a: CalibrationReport, b: CalibrationReport): CalibrationReport
```

### `calibrationSection`

```ts
calibrationSection(options?: CalibrationOptions): (result: EvalResult) => { calibration: CalibrationReport; }
```

Takes [`CalibrationOptions`](/docs/evaluation/reference/calibration#calibrationoptions). Returns a [`ResultSection`](/docs/evaluation/reference/runner#resultsection) that reads an [`EvalResult`](/docs/evaluation/reference/types#evalresult) and sets its `calibration` to a [`CalibrationReport`](/docs/evaluation/reference/types#calibrationreport).

Add calibration through the runner's result sections hook.

## Types

### `CalibrationOptions`

Calibration grouping, binning and empirical acceptance requirements.

{/* options: CalibrationOptions */}
| Option | Type | Description |
| --- | --- | --- |
| `bins` | `number` | Number of equal-width confidence bins. Default `10`. |
| `by` | `CalibrationReport["by"]` | How fields are grouped: `path`, `pattern`, `fieldType`, or `segment`. Default `pattern`. |
| `targetPrecision` | `number` | Precision that the lower confidence bound of an auto-accept threshold must reach. Default `0.99`. |
| `minSupport` | `number` | Fewest fields at or above a threshold before it can qualify. Default `5`. |
