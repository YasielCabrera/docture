Import these APIs from `docture/llm` or the narrow entries listed below. Install AI SDK 7 and Zod (3.25.76 or later 3.x, or 4.1.8 or later) in the application.
For model components:

```sh
npm install docture ai@^7 zod@^4
```

Also install the provider you construct, such as `@ai-sdk/openai`. The
[complete model install](/docs/getting-started/installation#text-extraction-classification-splitting-and-layout-with-a-model)
includes the document engine and schema library.

All `model` fields accept an AI SDK `LanguageModel`, including a provider instance or
gateway model string.

## Model backend

Import from `docture/llm`.

```ts
new LLM(languageModel: LanguageModel, options?: LlmOptions)
model(languageModel: LanguageModel, options?: LlmOptions): LLM
```

`LLM` implements core's `ModelBackend`. It creates text, vision, classifier, splitter,
and layout components that share one set of model options. Its `id` defaults to
`modelIdOf(model)`.

`LlmOptions` contains `name`, `completion`, `instructions`, `cache`, `pricing`,
`temperature`, and `maxRetries`. It also accepts `extraction`, `vision`, `classifier`, and
`splitter` and `layout` override objects. Splitter mode defaults to `text`; the other
value is `image`.
Completion defaults to `forbidden`, and temperature defaults to `0` in generated
components.

Model provider errors reject strategy and splitter calls. The pipeline records strategy
failures and may continue. The LLM classifier converts its own failures to abstentions.


## Extractor factory

Import from `docture/llm/extractor`.

```ts
createLlmExtractor(options: LlmExtractorOptions): Extractor
```

`LlmExtractorOptions` extends `ExtractorOptions` without `strategies`. It requires a
`model` and accepts `completion`, text strategy options under `llm`, deterministic
strategies under `before`, optional `vision`, and `classifyWithModel`.

`before` strategies are registered before the text model. `vision: true` adds a default
vision strategy; an object configures it. `classifyWithModel: true` appends an
`LlmClassifier`. Loader requirements and duplicate component errors follow core rules.

Both extraction capabilities call `generateText` with `Output.object`. They merge results
and account usage in document order even when requests finish out of order. A failure
aborts sibling requests and stops new requests. Multiple vision groups use a relaxed
fragment schema; core validates the merged result against the original contract.
`providerOptions` also applies to vision. Render and group settings separate cache entries.

The 20-page group default is conservative and remains subject to provider payload and
context limits. Original PNG or JPEG inputs from OCR loaders may ignore `format`, `dpi`,
and `maxEdge`, returning the source image unchanged. TIFF pages from the Tesseract loader
return PNG and ignore the same options. The AI SDK detects MIME from actual
bytes. Resize input images explicitly when a strict pixel limit is required.
