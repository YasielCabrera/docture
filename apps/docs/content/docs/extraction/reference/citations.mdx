Import from `docture`.

## Field citations

```ts
type FieldCitation =
  | { path: string; status: "verified"; ids: readonly [EvidenceSourceId, ...EvidenceSourceId[]]; minOcrConfidence?: number }
  | { path: string; status: "cited-unverified"; ids: readonly EvidenceSourceId[]; minOcrConfidence?: number }
  | { path: string; status: "uncited"; ids: readonly [] };
type CitationStatus = FieldCitation["status"];
```

A citing strategy, such as `llm({ model, citations: true })`, makes the result carry one
`FieldCitation` for each present leaf of `data`, in depth-first key and index order. A
present leaf is a value that is not an object or an array and is not `null`, `undefined`
or a blank string; `0` and `false` are present. `path` is a field path, the same text a
conflict or schema issue on that field uses.

- `verified`: the value was found in the cited evidence, and `ids` are exactly the records the
  match spans.
- `cited-unverified`: the cited records exist but do not show the value, or the caller's
  schema changed the value after the model answered. `ids` lists every cited record that
  exists and is empty when none did.
- `uncited`: the model cited nothing for the value, as for a schema default.

`minOcrConfidence` is the lowest OCR confidence, from 0 to 1, among the spans behind a cited
value. Use it to choose which values to inspect. It is evidence about the OCR, not a
probability that the value is right. Engines score text in units of different sizes:
Tesseract scores each word, and PaddleOCR scores each recognized region, so a region
score covers every word in it. Scores from two engines do not compare.

- For `verified`, it covers only the spans of the matched occurrence. A low-confidence
  word elsewhere on the same line does not lower it. When the value appears more than
  once in the cited lines, it describes the occurrence that `ids` names, the first in
  page and line order.
- For `cited-unverified`, it covers every span of every line in `ids`, so it is broader
  and usually lower.
- It is absent when any relevant span has no confidence in 0 to 1, as on a text layer,
  for an `uncited` value, when `ids` is empty, and when a line's text is not its spans
  joined by single spaces. Core reads every score from the loaded document's spans; a
  strategy can name spans but cannot supply a score.

`citationSources` holds only real `SourceLine` records (`id`, `pageNumber`, `box`, `text`)
for line IDs in `citations`, taken from the loaded document, so a page range keeps its original page
numbers. A box carries no page size; read it from the source you render. A strategy
reports citations through `StrategyOutcome.citations`, and the pipeline aligns them with
the validated data: it marks every other leaf `uncited`, drops an entry for a key the
schema stripped, and drops an id the document does not have.


Native element and cell IDs are also `EvidenceSourceId` values. Cited native records appear separately in `evidenceSources` as `SourceEvidence`, with actual granularity and optional locations. They have no fabricated printed lines. OCR confidence is absent when a citation includes native evidence. See [source evidence](/docs/conversion/evidence).
