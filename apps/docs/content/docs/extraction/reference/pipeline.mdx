These APIs expose the stages behind `Extractor` for custom composition, plus shared disposal and OCR fallback. Import them from `docture` or `docture/node`. Most applications use [`Extractor`](/docs/extraction/reference/extractor) instead.

## Low-level pipeline

### `runPipeline`

Runs one extraction with explicit components.

```ts
function runPipeline<T>(
  components: PipelineComponents,
  source: DocumentSource,
  schema: FlexibleSchema<T>,
  options?: RunOptions<T>,
): Promise<ExtractionResult<T>>
```

Resolves and loads the source, computes runtime features, classifies when needed, routes strategies, validates returned data, and returns the first validated result. Throws the typed failures listed in the [error reference](/docs/resources/errors). See [`PipelineComponents`](/docs/extraction/reference/extractor#pipelinecomponents) and [`RunOptions`](/docs/extraction/reference/extractor#runoptions).

### `readDocument`

Tries each eligible loader in order and returns the first that succeeds.

```ts
function readDocument(
  loaders: readonly DocumentLoader[],
  raw: RawDocument,
  logger: Logger,
  signal: AbortSignal,
  stageTimeoutMs: number | undefined,
  request?: LoadRequest,
): Promise<ReadDocument>
```

Throws `LoadFailedError`, carrying the loader attempts, when every accepting loader fails.

### `ReadDocument`

{/* options: ReadDocument */}
| Field | Meaning |
| --- | --- |
| `document` | The `LoadedDocument`. |
| `loader` | The loader that succeeded. |
| `attempts` | One entry per loader tried, in order. |

## Share disposal ownership

### `createDisposalScope`

Returns a scope that disposes each resource once.

```ts
function createDisposalScope(): DisposalScope
```

Core pipelines and `withRasterizer` pass the same scope to owned children, so a component shared by two owners is disposed once. Frozen resources are supported without replacing their methods. Create a new scope for each independent ownership lifetime.

### `DisposalScope`

Structural ownership shared by composed resources, including resources from another installed copy of Docture.

```ts
interface DisposalScope {
  dispose(...components: readonly ScopedDisposable[]): Promise<void>;
}
```

`dispose()` calls each component once in the scope and aggregates failures. See [scope disposal](/docs/extraction/lifecycle#scope-disposal).

### `ScopedDisposable`

A resource whose children can share the caller's scope.

```ts
interface ScopedDisposable {
  dispose?(scope?: DisposalScope): Promise<void>;
}
```

## OCR fallback

### `withOcrFallback`

Wraps a primary loader and rereads low-quality pages with a caller-selected OCR loader.

```ts
function withOcrFallback(
  primary: DocumentLoader,
  ocr: DocumentLoader,
  options?: OcrFallbackOptions,
): DocumentLoader & { dispose(scope?: DisposalScope): Promise<void> }
```

The [selected-page OCR guide](/docs/integrations/selected-page-ocr) defines replacement and warning behavior.

### `OcrFallbackOptions`

{/* options: OcrFallbackOptions */}
| Option | Default | Meaning |
| --- | --- | --- |
| `assess` | `textLengthQuality` | `(page: LoadedPage) => PageOcrQuality`. Scores a page; identify intentional blanks to leave them untouched. |
| `threshold` | `DEFAULT_OCR_THRESHOLD` (20) | Pages below this quality go to OCR. An OCR candidate must reach it while also improving on the original. |
| `minimumImprovement` | `0` | Required strict improvement beyond the original score. |

### `textLengthQuality`

The default `assess`. Scores a page by the length of its trimmed text.

```ts
function textLengthQuality(page: LoadedPage): PageOcrQuality
```

It returns `{ kind: "text", quality: page.text.trim().length }` for every page, so it cannot tell an intentionally blank page from a scan. A blank page is sent to OCR and keeps its original when OCR finds no text.

### `DEFAULT_OCR_THRESHOLD`

The default `threshold`, `20`. With `textLengthQuality`, a page with fewer than 20 characters of trimmed text goes to OCR.

### `PageOcrQuality`

The result of `assess`.

```ts check
type PageOcrQuality =
  | { readonly kind: "intentional-blank" }
  | { readonly kind: "text"; readonly quality: number };
```

### `OcrFallbackWarning`

Explains a page whose OCR failed or whose replacement was rejected.

```ts check
interface OcrFallbackWarning {
  readonly pageNumber: number;
  readonly code: "OCR_FAILED" | "OCR_PAGE_MISSING" | "NO_IMPROVEMENT" | "GEOMETRY_MISMATCH" | "OCR_NOT_ELIGIBLE";
  readonly message: string;
  readonly errorCode?: string;
}
```

### `OcrFallbackReport`

What one load did, page by page. The composition stores it in the loaded document's `meta.ocrFallback`, and `DocumentConverter` returns it as [`ConversionResult.ocrFallback`](/docs/conversion/reference/converter).

```ts check
import type { OcrFallbackWarning } from "docture";

interface OcrFallbackPage {
  readonly pageNumber: number;
  readonly supplier: "primary" | "ocr";
  /** Absent for an intentional blank. */
  readonly originalQuality?: number;
  /** Present when the OCR page replaced the original. */
  readonly candidateQuality?: number;
}

interface OcrFallbackReport {
  readonly primary: string;
  readonly ocr: string;
  readonly requestedPages: readonly number[];
  readonly pages: readonly OcrFallbackPage[];
  readonly warnings: readonly OcrFallbackWarning[];
  readonly primaryMs: number;
  readonly ocrMs: number;
  readonly totalMs: number;
  readonly externalCost: "not-reported";
}
```

`requestedPages` lists the pages sent to OCR. `pages` has one entry per loaded page, naming the loader that supplied it. `externalCost` is always `"not-reported"`, because OCR engines report no billed cost.

### Raster page caps

`RasterOptions.maxPages` caps the highest original page number before rasterization. Built-in PDF rasterizers apply it before allocating page images. Both OCR loaders forward their cap and omit total `pageCount` when the cap prevents them from establishing the original count. Selected pages retain their original numbers. A cap above the document length still reads the whole document.
