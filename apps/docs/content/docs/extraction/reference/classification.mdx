Import from `docture`.

## Classifications

`Classification<Name, S, E>` contains:

| Field | Required | Meaning |
| --- | --- | --- |
| `name` | yes | Literal document kind and result discriminant. |
| `description` | yes | Recognition guidance. |
| `schema` | yes | Schema used for this kind. |
| `hints` | no | Additional recognition or extraction guidance. |
| `extractor` | no | Extractor used only for this kind. |
| `extractionContract` | no | Contract used for extraction instead of `schema`. |
| `examples` | no | Worked examples typed by the extraction contract. When this kind is selected, they replace that contract's own. |
| `image` | no | Reference image path or bytes for supporting classifiers. |

```ts
defineClassification<
  const Name extends string,
  S extends FlexibleSchema,
  E extends ContractLike = S,
>(classification: Classification<Name, S, E>): Classification<Name, S, E>
```

`defineClassification()` preserves the literal name. It does not validate the schema or
check whether an image exists.

```ts
classificationOf<S extends FlexibleSchema>(
  contract: Contract<InferSchema<S>> & { schema: S },
  overrides?: Omit<Partial<Classification<string, S, S>>, "schema">,
): Classification<string, S, S>
extractionContractOf(classification: Classification): ContractLike
```

`classificationOf()` copies a contract's name, description, schema, hints, and examples, then
applies overrides. `extractionContractOf()` returns `extractionContract` when present and
otherwise returns `schema`.

`ClassificationNames<C>` is the union of names in a classification list.
`ClassifiedExtraction<C>` is the discriminated result union produced by `Process`; each
member contains `name`, typed `data`, full `result`, and 1-based original `pages`.


## Classifier contract

`Classifier` has a stable `name`, optional runtime `requires`, `classify(context)`, and
optional `dispose()`.

`ClassifyContext` contains the loaded `document`, runtime `features`, candidate kinds,
`signal`, `logger`, and optional `documentLabel`, the source's file name when it has one.

```ts
defineClassifier(classifier: Classifier): Classifier
```

The classifier method returns `ClassificationSignal | null`. `null` means abstain.
Classifier failures are recorded as abstentions unless they are caller aborts.

`ClassificationResponse<C>` contains the selected candidate name or `UNKNOWN`, confidence,
all signals, and the matched `classification` when known. If the candidate list is empty,
core allows a free-form classifier name and leaves `classification` absent.

`ClassifyOptions` has `strategy?: ConsensusStrategy` and `threshold?: number`.
`ConsensusStrategy` is `"consensus" | "higherOrder" | "consensusWithThreshold"`. The
default is `higherOrder` with threshold `0`.


## Classification trees

`ClassificationNode<C>` contains a classification and optional children.
`ClassificationTree` contains its root nodes.

```ts
classificationNode(classification, children?): ClassificationNode
classificationTree(nodes): ClassificationTree
isClassificationTree(value): value is ClassificationTree
flattenTree(tree): Classification[]
```

The construction helpers return the supplied values without external calls.
`flattenTree()` walks depth-first.

```ts
extractor.classify<const C extends readonly Classification[]>(
  source: DocumentSource,
  classifications?: C,
  options?: RunOptions,
): Promise<ClassificationResponse<C>>

extractor.classifyTree(
  source: DocumentSource,
  tree: ClassificationTree,
  options?: RunOptions,
): Promise<{ leaf: ClassificationResponse; path: readonly ClassificationResponse[] }>
```

Direct classification tries eligible loaders in order until one succeeds. Each loader
uses `stageTimeoutMs`; a failed or timed-out loader allows the next loader to run.
A `LoadedSource` skips loading. Eligible classifiers run concurrently with independent
deadlines, and their signals retain registration order. A classifier deadline becomes
an abstention. Caller cancellation stops classification and preserves its reason.

`ClassificationSignal` contains `classifier`, proposed `name` or `null`, `confidence`, and
optional `note` and `usage`. `ClassificationResult<Name>` contains the selected name or `UNKNOWN`,
confidence, and every signal.
