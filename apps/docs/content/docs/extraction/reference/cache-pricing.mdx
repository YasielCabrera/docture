Response caches skip repeated model requests, and price tables turn token counts into cost. Import them from `docture/llm/cache` and `docture/llm/pricing`, which need no model runtime. Both are also exported from `docture/llm`, whose model exports require `ai@^7` and a supported Zod release. [Configure prompts, caching, and pricing](/docs/extraction/model-settings) shows them in use.

```sh
npm install docture
```

## Cache

Import from `docture/llm/cache`.

### `LlmCache`

The interface a response cache implements. Pass one as `cache` to a model strategy or `LLM`.

```ts
interface LlmCache {
  get(key: string): Promise<CachedResponse | undefined>;
  set(key: string, value: CachedResponse): Promise<void>;
  clear?(): Promise<void>;
}
```

### `memoryCache`

A bounded least-recently-used cache in process memory.

```ts
function memoryCache(maxEntries = 500): LlmCache
```

It copies responses on reads and writes.

### `fileCache`

A disk cache with one JSON file per key, sharded two directory levels below `root`.

```ts
function fileCache(root: string): LlmCache
```

Missing or unreadable entries are cache misses. Write failures reject `set()`.

### `CachedResponse`

A stored model answer.

```ts
interface CachedResponse {
  readonly data: unknown;
  readonly usage: RawUsage;
}
```

`usage` keeps the raw token counts, including `inputTokenDetails` for provider cache reads and writes.

### `cacheKey`

Returns a SHA-256 hex digest of the request parts.

```ts
function cacheKey(parts: CacheKeyParts): string
```

### `CacheKeyParts`

Everything that identifies a model request.

{/* options: CacheKeyParts */}
| Field | Meaning |
| --- | --- |
| `provider` | Provider id. Capabilities resolve a string model to `"gateway"`. |
| `providerOptions` | Optional AI SDK provider options sent with the request. |
| `modelId` | Model id. |
| `temperature` | Sampling temperature. `undefined` hashes as `0`. |
| `system` | System prompt. |
| `prompt` | User prompt text that identifies the request. |
| `jsonSchema` | JSON Schema of the requested output. |
| `variant` | Optional request variant. |

### `fingerprint`

Hashes message content in order, including file bytes and media types, so a cache key changes when a page image changes.

```ts
function fingerprint(content: readonly ContentPart[]): string
```

### `ContentPart`

One part of a user message.

```ts check
type ContentPart =
  | { readonly type: "text"; readonly text: string }
  | { readonly type: "file"; readonly data: Uint8Array; readonly mediaType: string };
```

## Pricing and usage

Import from `docture/llm/pricing`.

### `ModelPricing`

US dollars per million tokens.

{/* options: ModelPricing */}
| Field | Meaning |
| --- | --- |
| `inputPerMillion` | Input token price. |
| `outputPerMillion` | Output token price. |
| `cacheReadPerMillion` | Optional price of provider cache reads. Defaults to the input price. |
| `cacheWritePerMillion` | Optional price of provider cache writes. Defaults to the input price. |

### `PricingTable`

Prices keyed by model id, such as `"gpt-5"` or `"openai/gpt-5"`.

```ts
type PricingTable = Readonly<Record<string, ModelPricing>>;
```

### `lookupPricing`

Finds the price for a model id.

```ts
function lookupPricing(modelId: string, pricing: PricingTable | undefined): ModelPricing | undefined
```

Checks the id as given, then without its `provider/` prefix, so a table keyed on `"gpt-5"` prices `"openai/gpt-5"`. Returns `undefined` when neither matches.

### `toUsage`

Normalizes provider usage into a `Usage` record and prices it when it can.

```ts
function toUsage(
  raw: RawUsage,
  wallMs: number,
  modelId?: string,
  pricing?: PricingTable,
): Partial<Usage>
```

Missing counts become zero. `costUsd` is added only when a price exists.

### `RawUsage`

Token counts as the AI SDK reports them.

```ts check
interface RawUsage {
  readonly inputTokens?: number;
  readonly outputTokens?: number;
  readonly totalTokens?: number;
  readonly inputTokenDetails?: {
    readonly noCacheTokens?: number;
    readonly cacheReadTokens?: number;
    readonly cacheWriteTokens?: number;
  };
}
```

### `Usage`

The normalized usage on every result, exported from `docture`. See [results API](/docs/extraction/reference/results#usage) for its fields.
