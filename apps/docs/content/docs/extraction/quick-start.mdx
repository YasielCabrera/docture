This example reads the text layer of a PDF and sends that text to an AI SDK model.

## Install

Node 22 or newer is required.

```package-install
docture pdfjs-dist@6.2.108 ai@^7 @ai-sdk/openai zod@^4
```

`pdfjs-dist` and `ai` are optional peers used by this example. The PDF.js adapter needs
`pdfjs-dist@6.2.108`; model calls need AI SDK 7 and a provider. This example uses
`@ai-sdk/openai`. See [other install recipes](/docs/getting-started/installation) or
[the migration guide](/docs/resources/migration).

## Read the result

The schema determines the type of `result.data`. TypeScript rejects fields that are not
in the schema.

The rest of the result explains the run:

| Field | Meaning |
|---|---|
| `method` | Strategy that returned data which passed validation |
| `loader` | Loader that read the document |
| `attempts` | Failed loaders followed by strategies that ran, with status, duration, usage, and errors |
| `features` | Page count, text length, document form, geometry, and rendering facts |
| `usage` | Input tokens, output tokens, total tokens, wall time, and optional cost |
| `validation` | Rule outcome for returned data; schema validation already accepted its shape |

When loader fallback succeeds, `attempts` includes each failed loader before the strategy
attempts. The successful loader is recorded in `result.loader`. If all eligible loaders
fail, `LoadFailedError.attempts` contains their errors and no extraction strategies run.

## Other return forms

Return only the data:

```ts
const invoice = await extractor.extractData("invoice.pdf", Invoice);
invoice.total;
```

Return failures as values:

```ts
const outcome = await extractor.safeExtract("invoice.pdf", Invoice);

if (outcome.ok) {
  console.log(outcome.result.data.total);
} else {
  console.error(outcome.error.message);
}
```
