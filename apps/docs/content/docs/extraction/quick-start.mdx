In this tutorial you generate a sample invoice PDF, define the fields you want from it, and extract them with a small parser. Every step runs locally on Node.js 22 or newer. You need a model API key only for the optional last step.

## Install

```sh
npm install docture zod pdfjs-dist
npm install --save-dev tsx pdfkit
```

`pdfjs-dist` reads the text layer of a PDF. `pdfkit` draws the sample invoice and `tsx` runs the scripts, so both are development dependencies. Docture declares `pdfjs-dist` and `pdfkit` as optional peers, so you install them explicitly. See [installation](/docs/getting-started/installation) for other document engines and model providers.

## Build the extractor

Create `extract.mts`:

<SourceExample file="quick-start/extract.ts" title="extract.mts" />

`readLabels` is an extraction strategy. `requires: ["TEXT_LAYER"]` limits it to documents with readable text. It finds each printed label and returns the value after it. When a label is missing, it throws, and the extractor reports a failure instead of accepting a partial answer.

The extractor loads `invoice.pdf` with PDF.js, runs `readLabels`, and validates its answer against `Invoice`.

Run it:

```sh
npx tsx extract.mts
```

## Read the result

The script prints:

```txt
{
  invoiceNumber: 'INV-2026-4311',
  issuedAt: '2026-02-01',
  total: 10768.68
}
read-labels used 0 model tokens
```

`result.data` has the type of `Invoice`, so TypeScript rejects a field that the schema does not define. `result.method` names the strategy whose answer passed validation. The result also records the loader, every attempt, validation, and usage; [inspect results](/docs/extraction/results) explains each one.

## Add a model

A parser reads only the layouts you write it for. To extract from documents you have not seen, let a model read the text. Install the AI SDK and the OpenAI provider:

```sh
npm install ai @ai-sdk/openai
```

Create `extract-with-a-model.mts`:

<SourceExample file="quick-start/with-a-model.ts" title="extract-with-a-model.mts" />

Run it with your OpenAI key:

```sh
OPENAI_API_KEY=your-key npx tsx extract-with-a-model.mts
```

`LLM` sends the PDF text and the schema, including its field descriptions, to the model. The extractor validates the model's answer against `Invoice`, as it did the parser's. The last line names the `llm` strategy and the tokens it used.

To keep the parser and call the model only when it fails, [add model fallback](/docs/extraction/without-a-model#add-model-fallback).
