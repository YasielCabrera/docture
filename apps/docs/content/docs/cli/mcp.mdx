title: Connect an MCP host

`docture mcp` serves conversion, inspection, and configured-schema extraction to an agent over the Model Context Protocol on stdin and stdout. The [MCP tool reference](/docs/cli/mcp-tools) lists each tool's arguments and results.

## Install the MCP SDK

The server needs the optional peer `@modelcontextprotocol/sdk`:

```sh
npm install --save-dev @docture/cli @modelcontextprotocol/sdk
```

Without the SDK, `docture mcp` exits with code `1` and names the version to install. The other commands never load it.

## Register the server with a host

Add the command to the host's MCP server configuration:

```json
{ "mcpServers": { "docture": { "command": "npx", "args": ["docture", "mcp"] } } }
```

The server reads `docture.config.*` once and keeps it for its lifetime. `--config` and `--no-config` work as for other commands. To let the `extract` tool run, configure a default `schema` or named `schemas` in the config. Model input can select a configured name, but cannot replace the schema, model, or credentials.

## Pass sources

A tool's `source` is a path relative to the directory the host starts the server in, an absolute path, or an http(s) or `file:` URL. `-` is not a valid source. `convert` returns content and writes no files or assets. With `pages`, it reads and converts only those pages and keeps their original numbers.

## Read results and errors

Each result is the version 1 envelope, as structured content and as JSON text. A failed document sets the MCP `isError` flag and reports `error.code`, for example `LOAD_FAILED`. A config that fails to load, or a config factory that throws or returns an invalid converter, answers the same way: one failed item with the code the CLI would report. For the core tools, missing or malformed arguments are JSON-RPC invalid-parameter errors. Invalid Paperless tool arguments return a failed envelope with code `USAGE` and set `isError`.

Stdout carries only protocol frames. Warnings go to stderr. The server stops at the end of its input or on Ctrl-C, and cancels calls still in flight.

To start the server from your own Node code, use [`createMcpServer`](/docs/cli/reference/cli#mcp-server).
