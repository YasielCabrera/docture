Compare two runs with paired significance tests

## Arguments

| Argument | Required | Meaning |
| --- | --- | --- |
| `base` | Yes | Baseline run id or run directory |
| `candidate` | Yes | Candidate run id or run directory |

## Flags

| Flag | Default | Meaning |
| --- | --- | --- |
| `--test <test>` | auto | Significance test: paired bootstrap for continuous metrics, McNemar for binary ones Choices: `auto`, `bootstrap`, `mcnemar`. |
| `--format <fmt>` | md | Markdown tables, or the comparison as JSON Choices: `md`, `json`. |
| `--experiment <id\|base:candidate>` | Not set | One experiment, or a baseline and candidate pair. Default: every shared experiment |
| `--store <dir>` | Not set | Run store directory. Default: the config's store, else .docture/eval beside the config |
| `--config <path>` | Not set | Eval config. Default: the nearest docture.eval.&#123;ts,mts,js,mjs&#125; |
| `--verbose`, `-v` | Not set | Report the wiring, the routing, and every attempt |
| `--quiet`, `-q` | Not set | Only failures and the first hint per error code on stderr |
| `--no-color` | Not set | Never emit ANSI colour |
| `--help`, `-h` | Not set | Show this help |

## Examples

```sh
docture eval compare <baseRunId> latest
docture eval compare base/ candidate/ --test mcnemar --format json
```
