Apply the config's gate to a stored run

## Arguments

| Argument | Required | Meaning |
| --- | --- | --- |
| `run` | Yes | A run id, latest, or a run directory |

## Flags

| Flag | Default | Meaning |
| --- | --- | --- |
| `--baseline <runId\|auto\|none>` | the run's stored comparison | Compare first, so regression budgets apply |
| `--format <fmt>` | text | Text for people; JSON prints the eval result or record as is Choices: `text`, `json`. |
| `--store <dir>` | Not set | Run store directory. Default: the config's store, else .docture/eval beside the config |
| `--config <path>` | Not set | Eval config. Default: the nearest docture.eval.&#123;ts,mts,js,mjs&#125; |
| `--verbose`, `-v` | Not set | Report the wiring, the routing, and every attempt |
| `--quiet`, `-q` | Not set | Only failures and the first hint per error code on stderr |
| `--no-color` | Not set | Never emit ANSI colour |
| `--help`, `-h` | Not set | Show this help |

## Examples

```sh
docture eval gate latest --baseline auto
```
