The service started by [`docture serve`](/docs/cli/http-service) accepts JSON POST requests on three routes. It accepts document bytes, not source paths or URLs.

## Routes

| Route | Request fields | Result |
| --- | --- | --- |
| `/convert` | `document`, optional `pages`, optional `format` | `content`, `format`, `mimeType`, `pageCount`, `loader`, `method`, and `warnings`, with assets embedded |
| `/inspect` | `document`, optional `pages` | The page and fact report of `inspect --format json` |
| `/extract` | `document`, `schema`, optional `pages` | Full data, validation, citation and evidence, and conflict fields |

## Request body

```json
{
  "document": { "data": "JVBERi0xLjMK...", "mimeType": "application/pdf", "fileName": "invoice.pdf" },
  "schema": "invoice"
}
```

| Field | Meaning |
| --- | --- |
| `document.data` | Required. The document bytes as nonempty canonical base64 |
| `document.mimeType` | Optional media type, at most 200 characters |
| `document.fileName` | Optional file name, at most 255 characters |
| `pages` | Optional nonempty array of one-based original page numbers |
| `format` | `/convert` only. `text`, `markdown`, `html`, or `json`. Default `markdown` |
| `schema` | `/extract` only. Required. A schema name the service was started with |

A field the route does not list fails with HTTP 400 before the document loads.

## Responses

Every response uses the version 1 CLI envelope. A document failure is still HTTP 200, with `ok: false` and an `error` with `code` and `message` on the result.

| HTTP status | Code | Transport failure |
| --- | --- | --- |
| 400 | `INVALID_REQUEST` | Invalid request |
| 401 | `UNAUTHORIZED` | Missing or invalid bearer token |
| 404 | `NOT_FOUND` | Unknown route |
| 405 | `METHOD_NOT_ALLOWED` | Method other than POST |
| 408 | `BODY_TIMEOUT` | Body deadline exceeded |
| 413 | `BODY_TOO_LARGE` | Encoded JSON body too large |
| 415 | `INVALID_REQUEST` | Unsupported content type |
| 500 | `SERVICE_FAILED` | Unexpected service failure |
| 503 | `SERVICE_BUSY` | Capacity full |
| 503 | `SERVICE_CLOSING` | Service is closing |
| 503 | `SERVICE_SHUTDOWN` | Shutdown deadline expired |

## Authentication and limits

The service binds to localhost by default. Other bindings require `DOCTURE_SERVE_TOKEN`, which clients send as `Authorization: Bearer <token>`. Configuration and schema selection stay fixed until restart.

The [`docture serve` flags](/docs/cli/commands/serve) set active requests, queue length, encoded body size, body deadline, and drain deadline. A client disconnect cancels its work. Shutdown stops admission and drains requests before it cancels them and disposes shared resources. An engine that ignores cancellation can delay the final exit. The [service API](/docs/cli/reference/service) exposes the same options to Node code.
