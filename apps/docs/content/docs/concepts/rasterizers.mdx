---
title: Rasterizers
description: Render document pages to PNG or JPEG independently of text loading.
---

A rasterizer turns document bytes into page images. It is separate from a loader so the
text library and rendering library can be selected independently.

Two rasterizers ship:

| Rasterizer | Engine | Platform code |
|---|---|---|
| `NapiCanvasRasterizer` | PDF.js and `@napi-rs/canvas` | Native prebuilt canvas binding |
| `MuPdfRasterizer` | MuPDF | WASM |

MuPDF is AGPL-3.0-or-later. Check the [package reference](/docs/reference/packages) before
shipping it in an application.

## Compose with a loader

```ts
const loader = withRasterizer(
  new DocumentLoaderPdfJs(),
  new NapiCanvasRasterizer({ dpi: 200 }),
);
```

`withRasterizer()` keeps the loader's text and geometry capabilities and changes the image
capability to `true`. Each loaded page receives an `image()` function.

## Lazy page images

`page.image()` renders one page on demand. The composition memoizes results by page number
and raster options.

```ts
const png = await document.pages[0]?.image?.({
  dpi: 200,
  format: "png",
  maxEdge: 2000,
});
```

Call `rasterizer.rasterize()` directly when you need several pages in one operation.

## Shipped rasterizer defaults

| Option | Default | Meaning |
|---|---|---|
| `dpi` | `300` | Requested render resolution |
| `format` | `png` | `png` or `jpeg` |
| `quality` | `0.9` | JPEG quality from 0 to 1 |
| `maxEdge` | none | Maximum pixel length of the longest edge |
| `pages` | all | 1-based page numbers to render |

`maxEdge` wins when the requested DPI would exceed the cap. `RasterPage.scale` is points
per pixel based on the rendered dimensions.
