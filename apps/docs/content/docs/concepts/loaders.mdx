title: Loaders

A loader accepts `RawDocument` bytes and returns a `LoadedDocument`.

```ts
interface DocumentLoader {
  readonly name: string;
  readonly capabilities: LoaderCapabilities;
  load(document: RawDocument, ctx: LoadContext): Promise<LoadedDocument>;
  dispose?(): Promise<void>;
}
```

## Built-in loaders

| Loader | Input | Output |
|---|---|---|
| `DocumentLoaderData` | Text, Markdown, CSV, HTML, JSON, XML | Text |
| `DocumentLoaderPdfJs` | PDF | Text and geometry |
| `DocumentLoaderMuPdf` | PDF | Text and geometry |
| `DocumentLoaderTesseract` | PNG, JPEG, and PDF with a rasterizer | OCR text, geometry, confidence, images |
| `DocumentLoaderPaddleOcr` | PNG, JPEG, and PDF with a rasterizer | OCR text, geometry, confidence, images |

The package name identifies the document library. Loader aliases such as `PdfJsLoader`
and `TesseractJsLoader` are also exported.

## Capabilities

`LoaderCapabilities` reports text, geometry, page-image support, accepted media types,
and optional custom facts.

```ts
new DocumentLoaderPdfJs().capabilities;
// {
//   text: true,
//   geometry: true,
//   images: false,
//   mimeTypes: ["application/pdf"]
// }
```

The boolean properties remain literal types. An API that accepts `GeometryLoader` or
`ImageLoader` can reject an incompatible loader during typechecking.

Strategy eligibility is a runtime decision. It uses facts found on the loaded document,
not only the loader's general capabilities.

## Loaded pages

Each page has a 1-based page number, dimensions in PDF points, and text. Geometry loaders
also return `TextLine` values with positioned `TextSpan` values.

Coordinates use a top-left origin. Lines are sorted from top to bottom and spans from left
to right.

`LoadedDocument.form` reports `digital`, `scanned`, `mixed`, or `unknown`. The loader name
appears in `result.loader`.

## Selection and failures

docture filters loaders by media type, then tries them in declaration order. A later
loader runs only when an earlier eligible loader throws.

`result.attempts` does not include loaders. `LoadFailedError.attempts` contains loader
failures when all eligible loaders fail.

[loader API pages](/docs/reference/api/loader-pdfjs) for options.
