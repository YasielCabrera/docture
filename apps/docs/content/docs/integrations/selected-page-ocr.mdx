---
title: Recover selected pages with OCR
description: Compose a primary loader and an explicit OCR fallback with caller-defined page quality.
type: how-to
---

`withOcrFallback` runs OCR only on the pages your text loader read poorly, and keeps every other page as the text loader returned it. Import it from `docture`.

## Compose the loaders

Pass the text loader, the OCR loader, and an `assess` callback with a `threshold` in the same units:

```ts check
import { withOcrFallback } from "docture";
import { DocumentLoaderPdfJs } from "docture/loaders/pdfjs";
import { DocumentLoaderTesseract } from "docture/loaders/tesseract";
import { NapiCanvasRasterizer } from "docture/raster/canvas";

const loader = withOcrFallback(
  new DocumentLoaderPdfJs(),
  new DocumentLoaderTesseract({ rasterizer: new NapiCanvasRasterizer() }),
  {
    threshold: 20,
    assess: (page) => ({ kind: "text", quality: page.text.trim().length }),
  },
);
```

Install the engines of the OCR loader you choose, as listed on the [Tesseract](/docs/integrations/tesseract) and [PaddleOCR](/docs/integrations/paddleocr) pages. Call `dispose()` on the composition when you finish with it.

{/* options: OcrFallbackOptions */}
| Option | Default | Meaning |
| --- | --- | --- |
| `assess` | required | Returns a `PageOcrQuality` for each page from the text loader. |
| `threshold` | required | Pages with a quality below this value go to OCR. |
| `minimumImprovement` | `0` | How much an OCR page must exceed the original quality to replace it. |

## Score page quality

`assess` returns `{ kind: "text", quality }` or `{ kind: "intentional-blank" }`. Return `intentional-blank` for pages that are meant to be empty, so OCR leaves them alone. Character count is a starting signal. Calibrate the callback on your own documents. `inferForm` labels the final document and does not select pages for OCR.

## Understand which pages are replaced

Only pages below the threshold reach OCR, and each OCR request names one original page. The built-in OCR loaders read only the requested page. A custom loader can ignore the page hint and read the whole document, so the composition cannot guarantee less work with such a loader.

An OCR page replaces the original when it reaches the threshold and improves the original quality by more than `minimumImprovement`. Otherwise the composition keeps the original page and adds an `OcrFallbackWarning`. That happens when OCR fails, returns no matching page, returns different page dimensions, does not improve enough, or the OCR loader does not accept the source's media type. Warnings are in the loaded document's `meta.ocrFallback.warnings` and are also logged. One page's failure leaves the other pages unaffected. A caller abort still cancels the whole document.

## Read the combined document

Replaced pages keep their original page numbers and known physical dimensions. Their lines, blocks, and source IDs come from OCR. When OCR supplies no page image, the text loader's lazy image function stays available. Document text and form are rebuilt from the selected pages. The composition accepts the text loader's MIME types and reports only the capability facts that both loaders report.

Per-page metadata names the loader that supplied the page, the quality scores, and the requested pages. It reports elapsed OCR time and unknown external cost separately from model token usage.

The repository example in [`apps/examples/20-input-loaders`](https://github.com/YasielCabrera/docture/tree/main/apps/examples/20-input-loaders), `ocr.ts`, runs an offline mixed-document example with stub loaders.
