The Canvas rasterizer renders PDF pages to PNG or JPEG with PDF.js and `@napi-rs/canvas`. Import `NapiCanvasRasterizer` and `napiCanvasRasterizer` from `docture/raster/canvas`.

## Install

```sh
npm install docture pdfjs-dist@^6.2.108 @napi-rs/canvas@^1.0.10
```

`@napi-rs/canvas` ships prebuilt native binaries for supported platforms. PDF.js and the canvas binding load on the first render. If either is not installed, the render fails with `MissingEngineError`.

## Rasterizer

### `NapiCanvasRasterizer`

Creates a rasterizer named `napi-canvas` that renders PDF pages to PNG or JPEG.

```ts
new NapiCanvasRasterizer(options?: NapiCanvasRasterizerOptions)
```

Per-call `RasterOptions` override the DPI, format, quality, maximum edge, and selected pages. The returned `RasterPage` values contain the unique selected pages in document order and report actual pixel dimensions and scale.

Pages are drawn on canvases from the `@napi-rs/canvas` copy that PDF.js loads. Rendering works when your package manager installs a separate canvas copy for PDF.js.

JPEG 2000 and JBIG2 images, common in scanned PDFs, are decoded with the WebAssembly decoders that ship in `pdfjs-dist`. PDF.js warnings, such as a note that it rebuilt a damaged cross-reference table, are not written to the console.

Opening, password, page decode, out-of-range page, render, encoding, and caller abort failures reject `rasterize()`.

### `napiCanvasRasterizer`

Returns the same rasterizer as `new NapiCanvasRasterizer(options)`.

```ts
napiCanvasRasterizer(options?: NapiCanvasRasterizerOptions): Rasterizer
```

### `NapiCanvasRasterizerOptions`

{/* options: NapiCanvasRasterizerOptions */}
| Option | Default | Meaning |
| --- | --- | --- |
| `dpi` | `300` | Render resolution. |
| `format` | `png` | Output format. |
| `quality` | `0.9` | JPEG quality from 0 to 1. |
| `maxEdge` | none | Maximum image edge in pixels. |
| `maxPixels` | `40000000` | Maximum pixels per page image. The DPI is lowered to fit; `Infinity` turns the cap off. |
| `password` | none | Password for an encrypted PDF. |

## Pair it with a loader

```ts check
import { withRasterizer } from "docture";
import { DocumentLoaderPdfJs } from "docture/loaders/pdfjs";
import { NapiCanvasRasterizer } from "docture/raster/canvas";

const loader = withRasterizer(
  new DocumentLoaderPdfJs(),
  new NapiCanvasRasterizer({ dpi: 300 }),
);
```

OCR loaders accept the rasterizer through their `rasterizer` option to read scanned PDFs. See [Extract from scans and images](/docs/integrations/scanned-documents) and [Compose page rasterizers](/docs/integrations/rasterizers).
