---
title: Read DOCX with Mammoth
description: Read DOCX text on one logical page with an optional Mammoth install.

---

`DocumentLoaderMammoth` reads the text of a DOCX file with Mammoth. Import it from `docture/loaders/mammoth`. The loader runs only in Node.js.

## Install Mammoth

```sh
npm install docture mammoth
```

Mammoth loads on the first `load()` call. If it is not installed, the call fails with [`MISSING_ENGINE`](/docs/resources/errors#error-catalogue).

## Convert a DOCX file

```ts check
import { DocumentConverter } from "docture";
import { DocumentLoaderMammoth } from "docture/loaders/mammoth";

async function convertDocx(docxBytes: Uint8Array) {
  const converter = new DocumentConverter({ loaders: [new DocumentLoaderMammoth()] });
  try {
    return await converter.convert({ bytes: docxBytes, mimeType: "application/vnd.openxmlformats-officedocument.wordprocessingml.document" }, { format: "text" });
  } finally {
    await converter.dispose();
  }
}
```

The loader accepts only DOCX. It reads the raw text with Mammoth's `extractRawText` and returns one logical page with zero width and height. Headings, paragraphs, and table cells keep their source order. Formatting, physical pagination, line geometry, and images are not available. Mammoth produces no HTML, and its access to external files stays disabled. Diagnostics log counts and types, never document content.

A page request can select page 1. Any other page fails with [`PAGE_OUT_OF_RANGE`](/docs/resources/errors#error-catalogue).

## Handle errors and cancellation

An invalid DOCX throws `MammothDocumentError` with code [`LOAD_FAILED`](/docs/resources/errors#error-catalogue) and the Mammoth error as its cause. The loader checks for cancellation before and after parsing. It cannot interrupt Mammoth while a parse runs.

The repository example in [`apps/examples/20-input-loaders`](https://github.com/YasielCabrera/docture/tree/main/apps/examples/20-input-loaders), `index.ts`, converts a real DOCX file without network access.
