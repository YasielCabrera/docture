---
title: Use extraction as an AI SDK tool
description: Borrow an extractor from an AI SDK tool with explicit source access.
---

`docture/llm/tool` exports `extractTool`, `ExtractToolOptions`, `ExtractionToolInput` and `ExtractionToolResult`. The tool has no model or extractor factory. It uses the caller's extractor and contract across invocations and never disposes them.

```ts
import { extractTool } from "docture/llm/tool";
import { resolveNodeSource } from "docture/node";
import type { Extractor, ContractLike } from "docture";

function toolsFor(extractor: Extractor, contract: ContractLike) {
  return { extract: extractTool({
    extractor, contract,
    async resolveSource(source, signal) {
      if (source !== "approved.txt") throw new Error("Source is not authorized.");
      return resolveNodeSource(source, signal);
    },
  }) };
}
```

Pass the returned tools to AI SDK `generateText`. Input contains one source string. `resolveSource` defines authorized paths or URLs and the working-directory policy. The example allows one relative path in the process working directory. Applications can resolve against a fixed directory or reject network sources.

Execution propagates the AI SDK abort signal through source resolution and extraction. Success returns `{ ok: true, result }` after JSON serialization. Dates therefore become strings. Failure returns `{ ok: false, error: { code, message } }`; cancellation uses `CANCELLED`. Raw Error instances do not cross this interface. An answer that cannot serialize returns a failure. Keep and dispose the extractor after its final invocation.
