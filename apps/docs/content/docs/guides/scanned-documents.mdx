title: Scanned documents
description: Extract from page images with OCR or a vision model.

A scanned PDF has no usable text layer. A text strategy such as `llm()` is not eligible
until OCR creates text. You can run OCR locally or send rendered pages to a vision model.

## Use a vision model

```sh
npm install docture pdfjs-dist@6.2.108 @napi-rs/canvas@1.0.10 ai@^7 @ai-sdk/openai zod@^4
```

Compose a rasterizer with the PDF loader, then add `vision()`:

```ts
import { createExtractor, withRasterizer } from "docture";
import { llm } from "docture/llm/text";
import { vision } from "docture/llm/vision";
import { DocumentLoaderPdfJs } from "docture/loaders/pdfjs";
import { NapiCanvasRasterizer } from "docture/raster/canvas";
import { openai } from "@ai-sdk/openai";

const model = openai("gpt-5");
const loader = withRasterizer(
  new DocumentLoaderPdfJs(),
  new NapiCanvasRasterizer({ dpi: 200 }),
);

const extractor = createExtractor({
  loaders: [loader],
  strategies: [llm({ model }), vision({ model })],
});
```

Digital PDFs use the text strategy first. A scan has no `TEXT_LAYER`, so the text
strategy is skipped and the vision strategy runs.

`vision()` groups at most 20 pages per request by default. Set `pagesPerRequest` to
match your provider's image limit, or `pageMode: "perPage"` for one request per page.
`maxPages` limits the total pages it sees. Calls run with concurrency 4 by default,
and partial results merge in page order.

## Use Tesseract OCR

Tesseract accepts PNG, JPEG, and multi-page TIFF files directly. It needs a rasterizer for PDFs. For the
canvas-backed PDF setup below:

```sh
npm install docture tesseract.js@7.0.0 pdfjs-dist@6.2.108 @napi-rs/canvas@1.0.10
```

```ts
import { DocumentLoaderTesseract } from "docture/loaders/tesseract";
import { NapiCanvasRasterizer } from "docture/raster/canvas";

const loader = new DocumentLoaderTesseract({
  rasterizer: new NapiCanvasRasterizer(),
  languages: ["eng"],
  dpi: 300,
});
```

The loader returns text, positioned words, confidence values, and lazy page images.
Tesseract runs in WASM. Language data is downloaded and cached unless `langPath` points to
local files.

## Use PaddleOCR

```sh
npm install docture ppu-paddle-ocr@6.3.0 onnxruntime-node@1.27.0 pdfjs-dist@6.2.108 @napi-rs/canvas@1.0.10
```

PaddleOCR reads TIFF files when `utif2@4.1.0` is also installed.

```ts
import { DocumentLoaderPaddleOcr } from "docture/loaders/paddleocr";
import { NapiCanvasRasterizer } from "docture/raster/canvas";

const loader = new DocumentLoaderPaddleOcr({
  rasterizer: new NapiCanvasRasterizer(),
  model: "v6Tiny",
  dpi: 300,
});
```

PaddleOCR uses `onnxruntime-node`, which loads a native prebuilt binding. Its detector and
recognizer models may be selected by name or supplied as local files, URLs, or bytes.

## Choose between OCR and vision

| Requirement | OCR | Vision model |
|---|---|---|
| Run offline | Yes | Provider dependent |
| Return reusable text and positions | Yes | No |
| Read handwriting or difficult photographs | Limited | Usually better |
| Pay model tokens | No | Yes |
| Feed a deterministic parser | Yes | No |

Test both paths on your own documents. OCR quality depends on language, resolution,
rotation, contrast, and page layout.

## Loader ordering is not OCR fallback

Loaders are selected by media type and declaration order. `DocumentLoaderPdfJs` can load a
scanned PDF successfully and return empty text. An OCR loader listed after it will not run
unless the first loader throws.

Use one of these setups:

- Send PDFs to a renderable PDF.js loader and use `vision()` for scans.
- Use an OCR loader as the PDF loader.
- Wrap the text-layer loader so it throws when `form` is `scanned`, then list OCR next.

When a later loader succeeds, failed loader attempts appear in `result.attempts`. The
successful loader appears in `result.loader`. If every eligible loader fails,
`LoadFailedError.attempts` contains all loader failures.

## Mixed documents

A mixed document has usable text on some pages and image-only content on others.
`features.form` reports `mixed`, but the whole document can still satisfy `TEXT_LAYER`.
A text strategy may therefore run without reading the image-only pages.

Use a vision strategy first when every page must be read as an image. Use an OCR loader
for the PDF when downstream code needs text and positions from every page. If the relevant
pages are known, pass them through `RunOptions.pages` and select the intended strategy with
`only`.

## Rendering details

Page images are lazy and memoized by raster options. Calling `page.image()` twice with the
same options renders once. `maxEdge` caps the longest edge even when the requested DPI
would produce a larger image.

See [rasterizers](/docs/concepts/rasterizers) for formats and coordinate scaling.
