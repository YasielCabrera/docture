`completion` controls how `LlmStrategy` handles the document text.

| Mode | Requests | Use it when |
|---|---|---|
| `forbidden` | One request | The document fits. This is the default. |
| `paginate` | One request per page | Each page contains useful standalone rows or fields. |
| `concatenate` | Page groups under a character budget | Several pages fit together but the full document does not. |

```ts
llm({ model, completion: "paginate" });

llm({
  model,
  completion: "concatenate",
  maxCharsPerRequest: 24_000,
});
```

`concatenate` splits only at page boundaries. A single page larger than the budget is sent
whole rather than cut through a table row.

## Fragment schemas

A page may contain only part of the requested result. For multi-request extraction,
docture removes `required` from the JSON Schema sent with each fragment. It keeps field
types and descriptions.

The pipeline merges the partial objects, then validates the merged value against the
original schema.

## Merge rules

`mergePartials()` applies these rules:

- Arrays concatenate in request order.
- Objects merge recursively.
- The first present scalar wins.
- `null`, `undefined`, and an empty string count as absent.

```ts
mergePartials([
  { invoiceNumber: "INV-1", rows: [{ id: 1 }] },
  { invoiceNumber: null, rows: [{ id: 2 }] },
]);
// { invoiceNumber: "INV-1", rows: [{ id: 1 }, { id: 2 }] }
```

## Vision pages

Vision extraction uses `pageMode` instead of `completion`:

```ts
vision({ model, pageMode: "together" }); // default
vision({ model, pageMode: "perPage" });
```

Per-page vision requests use the same relaxed-schema and merge behavior as text
pagination.

## Control cost

Every request repeats the system prompt, instructions, and schema. `result.usage` sums
usage reported by the winning strategy and by earlier strategies that returned usage.

Restrict extraction to known 1-based pages with `RunOptions.pages`:

```ts
await extractor.extract("invoice.pdf", Invoice, { pages: [1, 2, 3] });
```

For vision, `maxPages` selects the first pages before rendering. Text completion has no
separate page-count option; use `pages` when the relevant page numbers are known.
