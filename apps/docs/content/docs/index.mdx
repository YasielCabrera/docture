---
title: docture documentation
description: Extract structured data from documents in TypeScript.
---

docture reads a document and returns data that matches a schema. The schema also supplies
the TypeScript type of `result.data`.

You choose how docture reads the document and how it extracts the fields. A loader reads
PDF text, OCR output, or plain text. A strategy can call a model or run code you wrote.

## Smallest complete example

```ts
import { Extractor, LLM, contract } from "docture";
import { DocumentLoaderPdfJs } from "@docture/loader-pdfjs";
import { openai } from "@ai-sdk/openai";
import { z } from "zod";

const Invoice = contract({
  name: "invoice",
  description: "A commercial invoice.",
  schema: z.object({
    invoiceNumber: z.string(),
    total: z.number(),
  }),
});

const extractor = new Extractor()
  .loadDocumentLoader(new DocumentLoaderPdfJs())
  .loadLlm(new LLM(openai("gpt-5")));

try {
  const result = await extractor.extract("invoice.pdf", Invoice);
  console.log(result.data.invoiceNumber);
  console.log(result.data.total);
} finally {
  await extractor.dispose();
}
```

Start with the [quick start](/docs/quick-start) for installation and setup.

## What you install

The `docture` package re-exports `@docture/core` and `@docture/llm`. Loaders and
rasterizers stay in separate packages because each one brings its own document library.

| Need | Package |
|---|---|
| Core pipeline and model strategies | `docture` |
| PDF text and positions | `@docture/loader-pdfjs` |
| MuPDF text and page rendering | `@docture/loader-mupdf` |
| OCR with Tesseract | `@docture/loader-tesseract` |
| OCR with PaddleOCR | `@docture/loader-paddleocr` |
| Page rendering with PDF.js and canvas | `@docture/raster-canvas` |
| Accuracy scoring | `@docture/eval` |
| Test fixtures and conformance suites | `@docture/testing` |
| Terminal commands | `@docture/cli` |

See [packages](/docs/reference/packages) before choosing an OCR or rendering package.
Some packages use WASM. PaddleOCR and the canvas rasterizer use native prebuilt bindings.

## What comes back

`extract()` returns more than the extracted fields:

```ts
result.data;           // data inferred from the schema
result.method;         // strategy that produced the valid result
result.loader;         // loader that read the document
result.attempts;       // strategy attempts, in order
result.features;       // facts found on this document
result.usage;          // tokens, cost when priced, and wall time
result.validation;     // validation outcome
result.classification; // present when classification ran
```

Use `extractData()` when you only need the fields. Use `safeExtract()` when a failure
should be returned as a value instead of thrown.
