## Smallest complete example

Each quick start includes installation, runnable code, and the expected result.

## What you install

The four packages are `docture`, `@docture/cli`, `@docture/eval`, and `@docture/synthetic`. Add only the engines in your selected [installation recipe](/docs/getting-started/installation).

## What comes back

[Extraction results](/docs/extraction/results) include schema-inferred data, attempts, validation, and usage. Conversion returns content and source evidence. Evaluation returns scores and reports. Synthetic documents include ground truth and field locations.
