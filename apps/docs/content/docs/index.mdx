title: docture documentation
description: Extract structured data or convert PDFs to grounded text in TypeScript.

docture reads documents for strongly typed structured extraction and grounded conversion
to TXT, Markdown, or HTML.

You choose how docture reads the document and how it extracts the fields. A loader reads
PDF text, OCR output, or plain text. A strategy can call a model or run code you wrote.

## Smallest complete example

```ts
import { Extractor, contract } from "docture";
import { LLM } from "docture/llm";
import { DocumentLoaderPdfJs } from "docture/loaders/pdfjs";
import { openai } from "@ai-sdk/openai";
import { z } from "zod";

const Invoice = contract({
  name: "invoice",
  description: "A commercial invoice.",
  schema: z.object({
    invoiceNumber: z.string(),
    total: z.number(),
  }),
});

const extractor = new Extractor()
  .loadDocumentLoader(new DocumentLoaderPdfJs())
  .loadLlm(new LLM(openai("gpt-5")));

try {
  const result = await extractor.extract("invoice.pdf", Invoice);
  console.log(result.data.invoiceNumber);
  console.log(result.data.total);
} finally {
  await extractor.dispose();
}
```

Start with the [quick start](/docs/quick-start) for installation and setup.

## What you install

The two published packages are `docture` and `@docture/cli`. Core comes from the
`docture` root. Other capabilities use explicit subpaths, and each engine is installed
only when selected. See [installation recipes](/docs/guides/installation) for exact commands.

| Need | Import |
|---|---|
| Core pipeline | `docture` |
| Model components | `docture/llm` or `docture/llm/text` |
| PDF text and positions | `docture/loaders/pdfjs` |
| MuPDF text and page rendering | `docture/loaders/mupdf` |
| OCR with Tesseract | `docture/loaders/tesseract` |
| OCR with PaddleOCR | `docture/loaders/paddleocr` |
| Page rendering with PDF.js and canvas | `docture/raster/canvas` |
| Accuracy scoring | `docture/eval` |
| Test doubles | `docture/testing/doubles` |
| PDF fixtures | `docture/testing/fixtures` |
| Conformance suites | `docture/testing/conformance` |
| Terminal commands | `@docture/cli` |

See [packages and imports](/docs/reference/packages) before choosing an OCR or rendering
engine. MuPDF and Tesseract use WASM. ONNX Runtime and canvas use native prebuilt bindings.
For an existing application, follow the [migration guide](/docs/guides/migration).

## What comes back

`extract()` returns more than the extracted fields:

```ts
result.data;           // data inferred from the schema
result.method;         // strategy that produced the valid result
result.loader;         // loader that read the document
result.attempts;       // failed loaders, then strategy attempts
result.features;       // facts found on this document
result.usage;          // tokens, cost when priced, and wall time
result.validation;     // validation outcome
result.classification; // present when classification ran
```

Use `extractData()` when you only need the fields. Use `safeExtract()` when a failure
should be returned as a value instead of thrown.
