---
title: Trace content to source evidence
description: Follow page regions, line IDs, native pointers, and stable element identities.
type: how-to
---

Every element in a conversion result records the page, box, and source lines it came
from. Use that provenance to highlight a passage in the PDF or to cite it from an answer.

## Result provenance

Read each element's `provenance` for the page where it starts and its bounding box:

```ts
for (const page of result.pages) {
  for (const element of page.elements) {
    console.log(element.kind, element.provenance.pageNumber, element.provenance.box);
  }
}
```

Coordinates use PDF points with a top-left origin, x to the right, and y down. The
segment also lists the loader's `sourceIds` and, when the page has positioned lines, the
`lineIds` of the lines behind the element.

## Follow continued elements

A table or paragraph that continues across a page break has one segment per page.
`provenanceSegments()` returns them in page order:

```ts
import { provenanceSegments } from "docture";

for (const page of result.pages) {
	for (const element of page.elements) {
		console.log(element.id, provenanceSegments(element.provenance));
	}
}
```

A table built from positioned lines also has `rowProvenance`, which gives the page and box
of each row. See [cross-page continuation detection](/docs/conversion/reference/continuations)
for when elements join.

## Choose an ID to store

Store element IDs when you need an anchor that survives an unrelated edit. An element ID
describes the element's normalized content and position. Reflow, a different loader,
changed segmentation, or an inserted page can still change it, so treat it as an anchor,
not a checksum.

Store line IDs when you need the exact physical line. A line ID such as `p3-line-12` names
the twelfth positioned line on page 3. It is stable for the same file and loader, but an
inserted line renumbers the lines after it.

The [identity and evidence API](/docs/conversion/reference/evidence) lists the exact
stability limits of both.

## Keep native evidence

[Imported Docling documents](/docs/integrations/docling-import) can carry element and
table-cell evidence without physical line boxes. Keep that evidence and its source
identity with the document, and do not invent a page position when the input lacks one.
[Field citations](/docs/extraction/citations) link extracted values to supporting text.
