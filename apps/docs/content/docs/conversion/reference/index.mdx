`docture/llm/layout`. For task guides, start at the
[conversion and retrieval overview](/docs/conversion).

## Read layout and evidence

- [Semantic layout API](/docs/conversion/reference/layout): element and page types.

- [Running header and footer detection](/docs/conversion/reference/furniture): furniture rules and limits.
- [Table and merged-cell detection](/docs/conversion/reference/tables): table, header, and span rules.
- [Cross-page continuation detection](/docs/conversion/reference/continuations): when tables and paragraphs join across pages.
