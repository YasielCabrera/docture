Conversion marks running headers and footers as `page-header` and `page-footer` elements,
described in [`PageHeaderElement`](/docs/conversion/reference/layout#pageheaderelement)
and [`PageFooterElement`](/docs/conversion/reference/layout#pagefooterelement). This page
lists when a line becomes furniture and how each format renders it.

## Running headers and footers

Markdown and HTML leave furniture out of the body, so chunks built from that output do
not repeat a company name or page number per page. TXT and JSON keep it, in place at the
top and bottom of each page. A layout analyzer never receives furniture, and core ignores
annotations that name it.

```ts
const result = await converter.convert(source, { format: "markdown" });
const footers = result.pages.flatMap((page) =>
  page.elements.filter((element) => element.kind === "page-footer"),
);
console.log(footers.map((footer) => footer.text)); // ["Page 1 of 3", ...]
```

## Detection rules

Detection is a heuristic, not a measured accuracy claim.

- A tagged PDF's `header` or `footer` hint counts on a single page when the line lies in
  the top or bottom 10% of the page. The element's `evidence` is `tagged`.
- Without a tag, a line is eligible when it lies wholly in the top or bottom 10% of the
  page. It qualifies when the same text appears on at least three pages and on at least
  60% of all pages, of odd pages, or of even pages, within 2% of the page height of its
  median position. The element's `evidence` is `repeated`.
- A digit run matches across pages only when it follows the page number, as in
  `Page 2 of 9`.
- Between 10% and 15% of the page, only page-number text qualifies. It has digits with at
  most three words around them, no final `.`, `!`, or `?`, no bold type, and a different
  number on every page. Its position is within 1% of the page height and 2% of the page
  width of the median, with a gap of at least one line height to the body.
- Heading-size text, continuation lines such as `Table 4 (continued)`, table rows,
  text-only pages, and pages without dimensions are never inferred as furniture.

## Limits

- A one-page or two-page document gets furniture only from tags.
- Bold text between 10% and 15% of the page, such as a numbered `Question 1` heading,
  stays in the body.
- A band line whose text repeats within 2% of the page height on another page, without
  meeting these rules, is suspected furniture. An example is a running header on a
  two-page document. It stays body text outside any table, unless every copy is a table
  row, as a repeated header row is. A table never
  [continues across it](/docs/conversion/reference/continuations#continuation-rules).
