`DocumentConverter` turns a loaded document into text, Markdown, HTML, or versioned JSON.
Import it from `docture` to pass bytes or URLs, or from `docture/node` to also pass local
file paths. For a first run, see [Convert your first PDF](/docs/conversion/quick-start).

## Create a converter

### `DocumentConverter`

Create a converter and register its components.

```ts
import { DocumentConverter } from "docture/node";

new DocumentConverter(options?: DocumentConverterOptions)
```

A converter may start empty and receive loaders through `loadDocumentLoader()`. The
`docture/node` class reads local paths and file URLs. The `docture` class rejects them
unless you pass a `sourceResolver`.

| Method | Effect |
| --- | --- |
| `loadDocumentLoader(...loaders)` | Adds loaders in first-success order. Returns the converter. |
| `loadLayoutAnalyzer(analyzer)` | Sets the optional layout analyzer. Returns the converter. |
| `loadLlm(backend)` | Sets the backend's model layout analyzer. Throws `MissingComponentError` when the backend has no layout analyzer. |
| `loadLogger(logger)` | Replaces the logger. Returns the converter. |
| `components` | The registered loaders and the optional layout analyzer. |
| `dispose()` | Releases every disposable loader and analyzer once. Repeat calls return the same promise. Any teardown failure rejects with an `AggregateError` that lists every failure. The converter also implements `Symbol.asyncDispose`. After `dispose()`, conversion calls reject with `DisposedError`, and a conversion already in flight stops before it starts another loader or OCR page. |

A loader name already registered, or a second layout analyzer, throws
`DuplicateComponentError`.

### `createDocumentConverter`

Create a converter from options.

```ts
createDocumentConverter(options: DocumentConverterOptions): DocumentConverter
```

The `docture` export throws `MissingComponentError` when `options.loaders` is empty. The
`docture/node` export makes `options` optional and does not require a loader.

### `DocumentConverterOptions`

Construction options. Asset handling and output format are per-call options.

{/* options: DocumentConverterOptions */}
| Field | Type | Required | Meaning |
| --- | --- | --- | --- |
| `loaders` | `readonly DocumentLoader[]` | No | Loaders tried in order. The first eligible loader that succeeds with convertible text wins. |
| `layoutAnalyzer` | `LayoutAnalyzer` | No | Optional refinement applied after deterministic layout analysis. |
| `logger` | `Logger` | No | Default logger for every call. |
| `stageTimeoutMs` | `number` | No | Default per-stage deadline in milliseconds. Omit for none. |
| `sourceResolver` | `SourceResolver` | No | How sources are read. The `docture` default rejects local paths and file URLs. `docture/node` supplies file access. |

## Conversion calls

### `convert`

Convert one source.

```ts
convert(source: DocumentSource, options?: ConvertOptions): Promise<ConversionResult>
```

The converter copies `pages` when the call starts and sends it to the loader as
`LoadRequest.pages`, with the `layout` and `assets` hints. It then keeps only those pages,
also for preloaded sources and loaders that ignore the hint, and computes features,
layout, and assets from them. Results keep the original page numbers, and a table or
paragraph joins only across consecutive original pages.

A loader that succeeds but recovers no text from the selected pages does not end the
search. The converter records it in `attempts` with status `"skipped"` and error code
`NO_CONVERTIBLE_CONTENT`, then tries the next eligible loader. An OCR loader listed after
a text-layer loader therefore reads a document that is scanned throughout. To OCR only the
empty pages of a mixed document, wrap the text-layer loader with
[`withOcrFallback`](/docs/integrations/selected-page-ocr) instead. Extraction with
`Extractor` keeps the first loader that does not throw.

Throws:

- `PageSelectionError` with code `PAGE_OUT_OF_RANGE` for an empty page list, or a page
  that is not an integer or not in the document.
- `NoConvertibleContentError` with code `NO_CONVERTIBLE_CONTENT` when no eligible loader
  recovers text, as for a scan without OCR. Its `features` describe the first loader's
  document.
- `MissingEngineError` with code `MISSING_ENGINE` when every loader that threw lacks its
  engine, including an OCR loader that runs after an empty text layer.
- `DisposedError` with code `DISPOSED` after `dispose()`. `safeConvert` returns it as
  the error, and `convertBatch` throws it before yielding.
- `MissingComponentError` with code `MISSING_COMPONENT` when no loader is registered and
  the source is not an already loaded document.
- Loader errors with their own typed codes.

A layout analyzer failure does not throw. It adds a `LAYOUT_ANALYZER_FAILED` or
`INVALID_LAYOUT_ANALYSIS` warning and keeps the deterministic layout.

### `safeConvert`

Convert one source without throwing.

```ts
safeConvert(source: DocumentSource, options?: ConvertOptions): Promise<SafeConversion>
```

Returns a `SafeConversion`:

```ts
type SafeConversion =
  | { readonly ok: true; readonly result: ConversionResult }
  | { readonly ok: false; readonly error: Error };
```

### `convertBatch`

Convert many sources with bounded concurrency.

```ts
convertBatch(
  sources: readonly DocumentSource[],
  options?: ConversionBatchOptions,
): AsyncGenerator<ConversionBatchItem>
```

Yields a `ConversionBatchItem` for each source as it finishes, not in input order.
Leaving the generator early aborts in-flight jobs and waits for them to settle.

### `ConvertOptions`

Per-call options.

{/* options: ConvertOptions */}
| Field | Type | Required | Default | Meaning |
| --- | --- | --- | --- | --- |
| `format` | `ConversionFormat` | No | `"markdown"` | Output format. |
| `pages` | `readonly number[]` | No | Every page | Original one-based page numbers to convert. |
| `assets` | `ConversionAssetMode` | No | `"referenced"` | How the output refers to images. |
| `signal` | `AbortSignal` | No | None | Cancels the call. |
| `logger` | `Logger` | No | Converter logger | Logger for this call. |
| `stageTimeoutMs` | `number` | No | Converter value | Per-stage deadline in milliseconds. |

### `ConversionFormat`

```ts check
type ConversionFormat = "text" | "markdown" | "html" | "json";
```

See [Choose an output format](/docs/conversion/formats).

### `ConversionAssetMode`

```ts check
type ConversionAssetMode = "referenced" | "embedded" | "omit";
```

See [Export images and assets](/docs/conversion/assets).

### `ConversionBatchOptions`

`ConvertOptions` plus batch concurrency.

{/* options: ConversionBatchOptions */}
| Field | Type | Required | Default | Meaning |
| --- | --- | --- | --- | --- |
| `concurrency` | `number` | No | `4` | Documents converted at once. |
| `format` | `ConversionFormat` | No | `"markdown"` | Output format. |
| `pages` | `readonly number[]` | No | Every page | Original one-based page numbers to convert in each document. |
| `assets` | `ConversionAssetMode` | No | `"referenced"` | How the output refers to images. |
| `signal` | `AbortSignal` | No | None | Cancels the batch. |
| `logger` | `Logger` | No | Converter logger | Logger for each call. |
| `stageTimeoutMs` | `number` | No | Converter value | Per-stage deadline in milliseconds. |

### `ConversionBatchItem`

One finished batch job.

{/* options: ConversionBatchItem */}
| Field | Type | Required | Meaning |
| --- | --- | --- | --- |
| `source` | `DocumentSource` | Yes | The source as passed in. |
| `index` | `number` | Yes | The source's position in the input array. |
| `outcome` | `SafeConversion` | Yes | The result or the error. |

## Result

### `ConversionResult`

What `convert()` returns.

{/* options: ConversionResult */}
| Field | Type | Required | Meaning |
| --- | --- | --- | --- |
| `content` | `string` | Yes | Whole-document output. |
| `format` | `ConversionFormat` | Yes | The selected format. |
| `mimeType` | `string` | Yes | `text/plain`, `text/markdown`, `text/html`, or `application/json`. |
| `pages` | `readonly ConvertedPage[]` | Yes | Per-page fragments and semantic elements. |
| `assets` | `readonly ConversionAsset[]` | Yes | In-memory image assets. Empty in omit mode. |
| `loader` | `string` | Yes | Name of the loader that succeeded. |
| `method` | `string` | Yes | `deterministic`, or `deterministic+<analyzer name>` when a layout analyzer's annotations were applied. |
| `attempts` | `readonly Attempt[]` | Yes | Loader and layout analyzer history. |
| `warnings` | `readonly ConversionWarning[]` | Yes | Degraded layout, asset, link, and analyzer warnings. |
| `features` | `DocumentFeatures` | Yes | Runtime facts about the loaded document. |
| `usage` | `Usage` | Yes | Model tokens, optional cost, and the call's whole wall time. |
| `ocrFallback` | `OcrFallbackReport` | No | Present only when the loader was a [`withOcrFallback`](/docs/integrations/selected-page-ocr) composition. Names the pages sent to OCR, the loader that supplied each page, and per-page OCR warnings. JSON output does not include it. |

### `ConvertedPage`

One page of a conversion result.

{/* options: ConvertedPage */}
| Field | Type | Required | Meaning |
| --- | --- | --- | --- |
| `pageNumber` | `number` | Yes | One-based page number in the original document. |
| `width` | `number` | Yes | Page width in PDF points. |
| `height` | `number` | Yes | Page height in PDF points. |
| `content` | `string` | Yes | A format-specific fragment without the whole-document wrapper. It holds every element that starts on the page, including the rest of an element that continues onto later pages. |
| `elements` | `readonly DocumentElement[]` | Yes | The page's [semantic elements](/docs/conversion/reference/layout#semantic-layout). |
| `evidence` | `readonly SourceEvidence[]` | No | Native element and table-cell evidence, in every output format, when the input provides it. |

### `ConversionAsset`

An image returned with the result. It extends the loader's `LoadedAsset` with a stable
relative `reference`, such as `report.assets/page-1-image-1.png`, that referenced Markdown
and HTML link to. It also carries `id`, `pageNumber`, `name`, `mimeType`, `bytes`, the
`x`, `y`, `width`, and `height` of its box, and optional `widthPx`, `heightPx`, and `alt`.

### `ConversionWarning`

A non-fatal problem.

{/* options: ConversionWarning */}
| Field | Type | Required | Meaning |
| --- | --- | --- | --- |
| `code` | `ConversionWarningCode` | Yes | What went wrong. |
| `message` | `string` | Yes | A readable description. |
| `pageNumber` | `number` | No | The affected page, when one applies. |

### `ConversionWarningCode`

| Code | Meaning |
| --- | --- |
| `LAYOUT_DEGRADED` | Layout detection kept content apart or outside a table because the evidence was weak. |
| `AMBIGUOUS_READING_ORDER` | A page has overlapping text blocks with no unambiguous order. |
| `UNSUPPORTED_ASSET` | An asset has a duplicate ID or an unsupported media type, or a figure references a missing asset. |
| `UNSAFE_LINK` | A link target is unsafe. The output keeps the link text without the link. |
| `LAYOUT_ANALYZER_FAILED` | The layout analyzer threw or timed out. The deterministic layout was kept. |
| `INVALID_LAYOUT_ANALYSIS` | The layout analyzer returned invalid annotations. The deterministic layout was kept. |
