The root entry `@docture/synthetic` exports the constraints a model checks after sampling, plus the check-digit, random stream, and path helpers that generators use. The [scenarios guide](/docs/synthetic/scenarios) shows constraints in use.

## `@docture/synthetic`

### `ibanCheckDigits`

```ts
ibanCheckDigits(country: string, bban: string): string
```

The two ISO 13616 mod-97 check digits for a country and BBAN.

### `isValidIban`

```ts
isValidIban(value: string): boolean
```

Whether `value`, spaces ignored, is a well-formed IBAN with correct check digits.

### `luhnCheckDigit`

```ts
luhnCheckDigit(payload: string): number
```

The Luhn check digit to append to `payload`.

### `isValidLuhn`

```ts
isValidLuhn(value: string): boolean
```

Whether `value`, spaces ignored, ends in its correct Luhn check digit.

### `constraint`

```ts
constraint<T>(name: string, check: (value: T) => string | readonly string[] | undefined): Constraint<T>
```

A custom cross-field rule. Return a message, a list of messages, or nothing when satisfied.

### `sumOf`

```ts
sumOf<T>(items: PathPattern<T>, total: PathPattern<T>, options?: { readonly tolerance?: number }): Constraint<T>
```

The numbers at `items` sum to the number at `total`, within `tolerance`.

### `before`

```ts
before<T>(earlier: PathPattern<T>, later: PathPattern<T>, options?: { readonly orEqual?: boolean }): Constraint<T>
```

The ISO date at `earlier` precedes the one at `later`. Absent dates pass.

### `validIban`

```ts
validIban<T>(pattern: PathPattern<T>): Constraint<T>
```

Every value at `pattern` is a valid IBAN.

### `validLuhn`

```ts
validLuhn<T>(pattern: PathPattern<T>): Constraint<T>
```

Every value at `pattern` passes the Luhn check.

### `unique`

```ts
unique<T>(pattern: PathPattern<T>): Constraint<T>
```

Values at `pattern` are pairwise distinct.

### `valuesAt`

```ts
valuesAt(root: unknown, pattern: string): readonly (readonly [string, unknown])[]
```

Every concrete path and value at a pattern. Absent positions are skipped.

### `streamFor`

```ts
streamFor(seed: number | string, key: string): Stream
```

Returns the deterministic [`Stream`](#stream) for `key` under `seed`. Equal inputs give equal sequences on every platform.

### `formatPath`

```ts
formatPath(segments: readonly PathSegment[]): string
```

`["lineItems", 3, "amount"]` becomes `lineItems[3].amount`, the path format of `@docture/eval`.

### `formatPattern`

```ts
formatPattern(segments: readonly PathSegment[]): string
```

The pattern of a concrete position: indices become `[]`.

### `parsePath`

```ts
parsePath(text: string): PathSegment[] | undefined
```

Parse a concrete path or a pattern. `[]` parses to `-1`. Text that no path formats to returns `undefined`.

## Types

### `Constraint`

{/* options: Constraint */}
| Member | Meaning |
| --- | --- |
| `name` | The name reported in `SynthesisError.problems`. |
| `check` | `(value) => readonly string[]`. Returns one message per violation, or an empty list. |

### `Stream`

{/* options: Stream */}
| Method | Returns |
| --- | --- |
| `next` | `() => number`, a float in `[0, 1)`. |
| `int` | `(min, max) => number`, an integer in `[min, max]` inclusive. |
| `float` | `(min, max) => number`, a float in `[min, max)`. |
| `pick` | `(items) => T`, one of `items`. |
| `chance` | `(probability) => boolean`. |
| `fork` | `(key) => Stream`, an independent stream for a sub-key. |

### `PathSegment` and `PathPattern`

A `PathSegment` is an object key or an array index. `PathPattern<T>` names every schema position of `T` with `[]` for array items, such as `lineItems[].amount`.
