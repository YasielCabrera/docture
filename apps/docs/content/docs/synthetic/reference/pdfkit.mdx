`@docture/synthetic/pdfkit` renders `Template` values from `defineTemplate` to PDF with PDFKit and labels every printed field. It also renders any `SynthTemplate` through `renderTemplate`. The [PDF templates guide](/docs/synthetic/pdf-templates) shows it in use.

## `@docture/synthetic/pdfkit`

### `renderPdf`

```ts
renderPdf<T>(template: Template<T>, sample: Sample<T>, options?: RenderPdfOptions): Promise<SyntheticDocument>
```

Renders a `Sample` with a template into a PDF and labels every printed field with its page and box. Returns a [`SyntheticDocument`](/docs/synthetic/reference/documents#toevalcase). Throws `TemplateError` when the drawing and the printed mask disagree, a font lacks a glyph, or `draw` throws. Throws `MissingEngineError` when `pdfkit` is not installed.

### `renderTemplate`

```ts
renderTemplate<T>(template: SynthTemplate<T>, sample: Sample<T>, options?: RenderPdfOptions): Promise<SyntheticDocument>
```

Renders either kind of template. A PDFKit `Template` goes through `renderPdf` with every option. A `RenderingTemplate`, such as a React template, renders itself and receives only `createdAt`. The corpus writer and `docture synth` render through this function.

### `ENGINE_RANGES`

`{ pdfkit: ">=0.17.2 <0.21.0" }`. Every engine entry exports the ranges it supports under this name.

## Options

### `RenderPdfOptions`

{/* options: RenderPdfOptions */}
| Option | Default | Meaning |
| --- | --- | --- |
| `createdAt` | fixed date | Written as the PDF creation and modification date, so equal inputs give equal bytes. |
| `producer` | `@docture/synthetic` | The PDF Producer field. |
| `creator` | the template key | The PDF Creator field. |
| `title` | `<key> <scenario> <seed>` | The PDF Title field. |
| `compress` | `true` | Deflate content streams. |
