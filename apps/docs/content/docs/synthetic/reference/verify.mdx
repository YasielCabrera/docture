`@docture/synthetic/verify` reads a digital PDF back through PDF.js and checks every label against the text layer. It needs `pdfjs-dist`, loaded through `docture/loaders/pdfjs`. The [verification guide](/docs/synthetic/verification) shows it in use.

## `@docture/synthetic/verify`

### `verifyLabels`

```ts
verifyLabels(document: VerifiableDocument, options?: VerifyOptions): Promise<VerificationReport>
```

Checks that each label's box lies on its page and that the text spans meeting the grown box show the label's text. When the spans do not match as written, it compares the spans centred in the box with whitespace removed, because PDF.js reads letter-spaced text with a space between glyphs.

Returns a `VerificationReport`. Throws `RangeError` when `document.rendition.kind` is not `digital`, because a degraded rendition has no text layer.

### `assertVerified`

```ts
assertVerified(document: VerifiableDocument, options?: VerifyOptions): Promise<void>
```

Runs `verifyLabels` and throws `LabelVerificationError` with every failed label when the report is not `ok`. Call it on the digital rendering before you derive scans or photos from it.

## Types

### `VerifyOptions`

{/* options: VerifyOptions */}
| Option | Default | Meaning |
| --- | --- | --- |
| `tolerance` | `2` | Points each label box grows on every side before text spans are matched against it. |

### `VerifiableDocument`

```ts
type VerifiableDocument = Pick<SyntheticDocument, "bytes" | "mimeType" | "labels" | "rendition">;
```

The parts of a [`SyntheticDocument`](/docs/synthetic/reference/documents#toevalcase) that verification reads. Any rendered PDF document from `renderPdf`, `renderReactPdf`, or `renderHtmlPdf` qualifies.

### `VerificationReport`

{/* options: VerificationReport */}
| Field | Type | Meaning |
| --- | --- | --- |
| `ok` | `boolean` | `true` when no label failed. |
| `checked` | `number` | Number of labels checked. |
| `failures` | `readonly LabelFailure[]` | One entry per failed label, each with `path`, `kind`, `pageNumber`, and `message`. |

Each [`LabelFailure`](/docs/synthetic/reference/errors#labelverificationerror) has one of three kinds:

| Kind | Cause |
| --- | --- |
| `page-overflow` | The box extends past the edge of its page. |
| `outside-box` | The page shows the text, but not inside the box. |
| `missing` | The page does not show the text, or the label names a page the document does not have. |
