`@docture/synthetic/html` prints HTML templates with Chromium through `playwright-core` and labels each marked element with its box. Install a Chromium build separately. The [HTML templates guide](/docs/synthetic/html-templates) shows it in use.

## `@docture/synthetic/html`

### `defineHtmlTemplate`

```ts
defineHtmlTemplate<T>(): (definition: HtmlTemplateDefinition<T>) => HtmlTemplate<T>
```

Defines an HTML template for values of type `T`: `defineHtmlTemplate<Invoice>()({ ... })`. `render(value, format)` returns the body as one `<section class="page">` per page, each fixed to the page size, so pagination is explicit. Every printed field sits in an element with `data-field="<concrete path>"`, or several comma-separated paths.

Returns an `HtmlTemplate<T>` with `aliases` and `tags` defaulted to empty and the page size defaulted to A4.

### `renderHtmlPdf`

```ts
renderHtmlPdf<T>(template: HtmlTemplate<T>, sample: Sample<T>, options?: RenderHtmlPdfOptions): Promise<SyntheticDocument>
```

Prints the template with Chromium and labels each `data-field` element with its box in points. Verify the result with `verifyLabels` like a PDFKit rendering. Throws `TemplateError` when a field lies outside its page or the fields and the printed mask disagree. Throws `MissingEngineError` when `playwright-core` is not installed.

### `escapeHtml`

```ts
escapeHtml(text: string): string
```

Escapes `&`, `<`, `>`, `"`, and `'` so text is safe in HTML content or a quoted attribute.

### `ENGINE_RANGES`

`{ "playwright-core": "1.64.1" }`. Install a Chromium build separately.

## Types

### `HtmlTemplateDefinition`

{/* options: HtmlTemplateDefinition */}
| Field | Default | Meaning |
| --- | --- | --- |
| `key` | required | Unique template name used by selectors and case ids. |
| `aliases` | `[]` | Other names that select the template. |
| `family` | required | Group name for templates of one document kind. |
| `tags` | `{}` | Values copied into each case's tags. |
| `page` | `{ size: pageSizes.A4 }` | Page size in points. |
| `locale` | required | The `Locale` passed to `render` as a formatter. |
| `printed` | required | The [printed mask](/docs/synthetic/reference/templates#prints) for every schema field. |
| `css` | none | Stylesheet added after the page rules. Embed fonts as data URLs, because the renderer fetches nothing. |
| `render` | required | `(value, format) => string`, the HTML body. |

Ligatures are off unless the template sets them with `!important`, because PDF.js reads a ligature glyph as its own span.

### `HtmlTemplate`

{/* options: HtmlTemplate */}
| Field | Meaning |
| --- | --- |
| `key` | The template key. |
| `aliases` | Alternative names, empty when none were given. |
| `family` | The template family. |
| `tags` | Tags, empty when none were given. |
| `page` | `{ size }` with the resolved page size. |
| `locale` | The template locale. |
| `printed` | The printed mask. |
| `css` | The stylesheet, when one was given. |
| `render` | The render function. |

### `RenderHtmlPdfOptions`

{/* options: RenderHtmlPdfOptions */}
| Option | Default | Meaning |
| --- | --- | --- |
| `browser` | none | A Playwright Chromium `Browser` to reuse across renders. Without one, the renderer launches a browser and closes it after the call. |
| `createdAt` | fixed date | Written as the PDF creation and modification date, so equal inputs give equal bytes. |
| `executablePath` | Playwright's installed build | The Chromium executable to launch when no `browser` is given. |
