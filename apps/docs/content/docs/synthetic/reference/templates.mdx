The root entry `@docture/synthetic` defines what a template prints and how it draws. Templates from `defineTemplate` render with [`@docture/synthetic/pdfkit`](/docs/synthetic/reference/pdfkit). The [PDF templates guide](/docs/synthetic/pdf-templates) and the [printed fields guide](/docs/synthetic/printed-fields) show these APIs in use.

## `@docture/synthetic`

### `prints`

```ts
prints<V, R = never>(print: (value: NonNullable<V>, root: R) => unknown): Printed<V, R>
```

Declares a position printed as `print(value)` rather than as its value. The label and the ground truth hold what the page lets a reader recover, such as a plan name that two tariffs share. Return `null` when nothing is printed.

A `PrintedMask<T>` must name every key of `T`, optional ones included, so a new schema field fails to compile until each template decides. Each position is a `Flag`: `true`, `false`, a predicate over the value, its root and its parent, or a `prints()` transform. Objects take an `ObjectMask` per key and arrays take `{ items }`.

### `project`

```ts
project<T>(mask: PrintedMask<T>, root: T): Projection
```

The ground truth a template promises (`expected`, with every unprinted position `null`) and the label value of each printed leaf by concrete path (`leaves`). Renderers call it; call it yourself to inspect a mask.

### `locales`

```ts
locales["en-US"] locales["en-GB"] locales["de-DE"] locales["fr-FR"] locales["es-ES"]
```

Locale presets for numbers, money, and dates. Each is a [`Locale`](#locale). The presets use `-` as the minus sign because the standard PDF fonts cannot draw U+2212.

### `formatter`

```ts
formatter(locale: Locale): Formatter
```

Returns a `Formatter` for `locale`, described under [formatting types](#formatting-types). Formatting uses explicit patterns rather than `Intl`, so printed text and PDF bytes do not change with the runtime's ICU version.

### `defineTemplate`

```ts
defineTemplate<T>(): (definition: TemplateDefinition<T>) => Template<T>
```

Defines a template for values of type `T`: `defineTemplate<Invoice>()({ ... })`. The definition fields are listed under [`TemplateDefinition`](#templatedefinition). `draw` receives a [`Surface<T>`](#surface) in PDF points with a top-left origin.

`fonts` maps names to a `FontSource`: a standard PDF font name or the bytes of a TrueType or OpenType font. The renderer checks every drawn character against the font and fails with `TemplateError` (`missing-glyph`) when a glyph is absent, instead of printing a blank or a substitute.

### `defaultFonts`

```ts check
defaultFonts: { regular: "Helvetica"; bold: "Helvetica-Bold"; italic: "Helvetica-Oblique"; mono: "Courier" }
```

The font names every template can use without declaring them.

### `pageSizes`

```ts
pageSizes.A4 pageSizes.A5 pageSizes.Letter pageSizes.Legal
```

Page sizes in points.

### `selectTemplates`

```ts
selectTemplates<Selected extends Pick<SynthTemplate<unknown>, "key" | "aliases" | "family">>(registry: readonly Selected[], selectors: readonly string[]): readonly Selected[]
```

Resolves selectors by key, alias, family or `all`, keeping registry order and dropping duplicates. The registry can mix PDFKit and React templates. An unknown selector throws `RangeError` listing the known keys.

### `RenderingTemplate` and `SynthTemplate`

A `RenderingTemplate<T>` renders itself through an engine entry. It has the identity fields of a template (`key`, `aliases`, `family`, `tags`, `locale`, `printed`) and `renderDocument(sample, { createdAt })`. [React templates](/docs/synthetic/reference/react-pdf) are rendering templates.

`SynthTemplate<T>` is `Template<T> | RenderingTemplate<T>`, the type that `defineSynthConfig`, `writeCorpus`, and `renderTemplate` accept. Code that receives one tells the kinds apart with `"draw" in template`.

### `drawTable`

```ts
drawTable<T, Item>(surface: Surface<T>, options: TableOptions<Item>): number
```

Draws a paginated table from measured row heights. Rows never split across pages and the header repeats on each page. Cells of columns with a `key` are labeled as `<path>[i].<key>`. `reserveAfter` keeps room for a closing block, and `onPage` runs on each new page before the header, for running headers. Returns the y below the last row on the page where the closing block fits. The options are listed under [`TableOptions`](#tableoptions).

## Template types

### `TemplateDefinition`

{/* options: TemplateDefinition */}
| Field | Default | Meaning |
| --- | --- | --- |
| `key` | required | Unique template name used by selectors and case ids. |
| `aliases` | `[]` | Other names that select the template. |
| `family` | required | Group name for templates of one document kind. |
| `tags` | `{}` | `TagValue` entries copied into each case's tags. |
| `page` | `{ size: pageSizes.A4, margin: 50 }` | Page size and margin in points. |
| `locale` | required | The `Locale` passed to `draw` as a formatter. |
| `fonts` | `{}` | Font names mapped to a `FontSource`. `regular`, `bold`, `italic`, and `mono` default to [`defaultFonts`](#defaultfonts). |
| `printed` | required | The printed mask for every schema field. |
| `draw` | required | `(surface, value, format) => void`. |

A `FontSource` is a standard PDF font name or the bytes of a TrueType or OpenType font.

### `Surface`

{/* options: Surface */}
| Member | Meaning |
| --- | --- |
| `pageNumber` | The current page, starting at 1. |
| `size` | The page size in points. |
| `field` | `(path, text, at) => LayoutBox`. Draws text for one or more concrete paths and labels each with the drawn box. |
| `text` | `(text, at) => LayoutBox`. Draws text that is not a field. |
| `rule` | `(from, to, style?) => void`. Draws a line. `style` takes `width` and `color`. |
| `rect` | `(box, style?) => void`. Draws a rectangle. `style` takes `fill`, `stroke`, and `width`. |
| `image` | `(bytes, box) => void`. Draws an image into a box. |
| `measure` | `(text, style?) => { width, height }`. Returns the box text would occupy, without drawing. |
| `addPage` | `() => void`. Starts a new page. Later draws land on it. |

### `TextStyle` and `At`

| Field | Meaning |
| --- | --- |
| `font` | A font name declared by the template, or `regular`, `bold`, `italic`, or `mono`. Default `regular`. |
| `size` | Font size in points. Default 10. |
| `color` | Text color. Default `#000000`. |
| `align` | `left`, `right`, or `center`. With `width`, aligns inside `[x, x + width]`. Without it, `right` and `center` anchor at `x`. |
| `width` | Wrap width. Text never wraps without one. |
| `lineGap` | Extra space between wrapped lines, in points. |

An `At` is a `TextStyle` plus a position:

{/* options: At */}
| Field | Meaning |
| --- | --- |
| `x` | Left edge in points. |
| `y` | Top of the text box in points. |
| `font` | As in `TextStyle`. |
| `size` | As in `TextStyle`. |
| `color` | As in `TextStyle`. |
| `align` | As in `TextStyle`. |
| `width` | As in `TextStyle`. |
| `lineGap` | As in `TextStyle`. |

### `Projection`

{/* options: Projection */}
| Field | Type | Meaning |
| --- | --- | --- |
| `expected` | `unknown` | The value with every unprinted position `null`. A group or array with nothing printed collapses to `null`. |
| `leaves` | `ReadonlyMap<string, unknown>` | The label value of each printed leaf, keyed by concrete path. |

## Table types

### `TableOptions`

{/* options: TableOptions */}
| Option | Default | Meaning |
| --- | --- | --- |
| `path` | required | The concrete path of the array, such as `lineItems`. |
| `items` | required | The rows to draw. |
| `columns` | required | `TableColumn` definitions, left to right. |
| `x` | required | Left edge of the table. |
| `y` | required | Top of the table on the first page. |
| `bottom` | required | Lowest y a row may reach on each page. |
| `continueAt` | required | Top of the table on continuation pages. |
| `reserveAfter` | `0` | Space to keep free under the last row for a closing block. When it does not fit, the block starts on a new page. |
| `style` | none | `TextStyle` for cells. |
| `headerStyle` | none | `TextStyle` for the header row, applied over `style`. |
| `padding` | `3` | Cell padding in points. |
| `onPage` | none | Called on each new page before the header repeats, for running headers. |

### `TableColumn`

{/* options: TableColumn */}
| Field | Default | Meaning |
| --- | --- | --- |
| `header` | required | Header text. |
| `width` | required | Column width in points. |
| `align` | `left` | `left`, `right`, or `center`. |
| `key` | none | The item key this column prints. Cells of keyed columns are labeled as fields. |
| `text` | required | `(item, index) => string`, the cell text. |

## Formatting types

### `Locale`

{/* options: Locale */}
| Field | Meaning |
| --- | --- |
| `code` | Locale code, such as `de-DE`. |
| `decimal` | Decimal separator. |
| `group` | Thousands separator. |
| `date` | Default date pattern. `DD`, `MM`, `YYYY`, and `MON` (short month name) are replaced. |
| `months` | Short month names, January first. |
| `currency` | `{ symbol, position, space }`, where `position` is `before` or `after`. |
| `minus` | The minus sign. |

### `Formatter`

{/* options: Formatter */}
| Member | Meaning |
| --- | --- |
| `locale` | The `Locale` it formats for. |
| `number` | `(value, decimals?) => string`. A number with `decimals` places and grouping. |
| `money` | `(minor, { symbol?, decimals? }?) => string`. Integer minor units, such as cents, as money. |
| `date` | `(iso, pattern?) => string`. An ISO date in the locale's pattern or `pattern`. |
