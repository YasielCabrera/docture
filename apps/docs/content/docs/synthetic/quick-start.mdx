In this tutorial you create a one-page bill with two fields, render it to `bill.pdf`, and check that each label points to the printed text. You need Node.js 22 or newer. No model credentials are needed.

## Install

```sh
npm install --save-dev @docture/synthetic docture zod pdfkit pdfjs-dist tsx
```

## Define the model and template

Create `bill.mts`. It exports the schema, a model that samples values, and a template that draws them. Later guides import `model`, `template`, and `Bill` from this file.

```ts check
import { defineModel, defineTemplate, gen, locales } from "@docture/synthetic";
import { z } from "zod";

export const Bill = z.object({ customerName: z.string(), totalCents: z.number().int() });
export type Bill = z.infer<typeof Bill>;

export const model = defineModel(Bill, {
	fields: { customerName: gen.pick(["Dana", "Kenji"]), totalCents: gen.int(100, 9000) },
});

export const template = defineTemplate<Bill>()({
	key: "simple-bill",
	family: "bill",
	locale: locales["en-US"],
	printed: { customerName: true, totalCents: true },
	draw(page, bill, format) {
		page.field("customerName", bill.customerName, { x: 50, y: 50 });
		page.field("totalCents", format.money(bill.totalCents), { x: 50, y: 80 });
	},
});
```

## Render and verify

Create `synth.mts` next to it:

```ts
import { writeFile } from "node:fs/promises";
import { renderPdf } from "@docture/synthetic/pdfkit";
import { assertVerified } from "@docture/synthetic/verify";
import { model, template } from "./bill.mjs";

const document = await renderPdf(template, await model.sample({ seed: 1 }));
await assertVerified(document);
await writeFile("bill.pdf", document.bytes);
console.log(document.labels.map((label) => `${label.path}: ${label.text}`));
```

Run `npx tsx synth.mts`. It writes `bill.pdf` and prints the path of each label with the text drawn for it:

```txt
[ 'customerName: Dana', 'totalCents: $20.58' ]
```

Each label also records the ground-truth `value`, the `pageNumber`, and the `box` in PDF points. `document.expected` holds the values a reader can recover from this page. The same seed gives the same values and the same PDF bytes on every run.
