---
title: Evaluate a synthetic corpus
description: Read corpus truth and source locations with the evaluation package.
---

Install `@docture/eval` alongside `@docture/synthetic` and `docture`. `jsonlDataset` reads the manifest returned by `writeCorpus`.

Each case includes tags for template, family, scenario, rendition, severity, and locale, plus a `group` shared by the renditions of one rendering. Expected `locations` come from the transformed label boxes. Preserve groups in comparisons so related renditions do not count as independent ground truths.

## Choose the scored view

Project truth with `toExpected` when a processor returns only part of the original schema. Permit `null` for fields that a template does not print. Use explicit field comparators and array matching rules with `defineEval`.

Add slices such as `rendition: "tags.rendition"` to find failures hidden by an overall score. `groundingSection()` compares processor evidence with expected locations; it does not infer evidence for a processor that returns none.

For an in-memory rendering, `toEvalCase(document)` produces the case shape without a runtime dependency on eval. It includes ground truth, labels grouped by path, rendition tags, and rendering group identity.
