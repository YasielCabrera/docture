docture components are structural TypeScript interfaces. You do not extend a base class.
The `define*` helpers preserve literal types and improve inference.

## Install

```sh
npm install docture zod
```

See [installation recipes](/docs/getting-started/installation) for other engines and providers.

## Loader

A loader turns `RawDocument` bytes into a `LoadedDocument`.

```ts
const csvLoader = defineLoader({
  name: "csv",
  capabilities: {
    text: true,
    geometry: false,
    images: false,
    mimeTypes: ["text/csv"],
  },
  async load(raw, ctx) {
    ctx.signal.throwIfAborted();
    const text = new TextDecoder().decode(raw.bytes);

    return {
      pages: [{ pageNumber: 1, width: 0, height: 0, text }],
      text,
      form: inferForm([text.trim().length]),
      loader: "csv",
    };
  },
});
```

Use 1-based page numbers. Throw when the loader cannot read the bytes so another loader
can try. Report `form` and capabilities from what the loader actually produces.

For positioned words, use `linesFromWords()` and `textFromLines()` to create the same
geometry shape as the built-in loaders.

## Rasterizer

A rasterizer converts selected pages into PNG or JPEG bytes:

```ts
const rasterizer = defineRasterizer({
  name: "acme-renderer",
  formats: ["png"],
  async rasterize(raw, options, ctx) {
    ctx.signal.throwIfAborted();
    return renderPages(raw.bytes, options);
  },
});
```

Each `RasterPage` reports pixel dimensions, format, page number, and points per pixel in
`scale`. Compose it with a loader through `withRasterizer()` when strategies need lazy
page images.

## Strategy

```ts
const parser = defineStrategy({
  name: "invoice-parser",
  requires: ["TEXT_LAYER", "GEOMETRY"],
  async extract(ctx) {
    const data = parseInvoice(ctx.document);
    if (data === undefined) throw new Error("layout not recognized");
    return { data };
  },
});
```

Return data or throw. Do not return an empty placeholder to abstain. The pipeline validates
the returned value.

## Classifier

```ts
const classifier = defineClassifier({
  name: "document-heading",
  requires: ["TEXT_LAYER"],
  async classify(ctx) {
    if (ctx.document.text.includes("INVOICE")) {
      return {
        classifier: "document-heading",
        name: "invoice",
        confidence: 0.99,
      };
    }
    return null;
  },
});
```

Return `null` to abstain. A classifier should not throw. The pipeline converts a thrown
classifier into an abstention so other classifiers still run.

## Splitter

```ts
const splitter = defineSplitter({
  name: "invoice-heading",
  requires: ["TEXT_LAYER"],
  async belongsToSameDocument(first, second) {
    const startsInvoice = /^INVOICE\b/m.test(second.text);
    return {
      belongsToSameDocument: !startsInvoice,
      classificationPage1: "invoice",
      classificationPage2: "invoice",
    };
  },
});
```

`belongsToSameDocument()` judges two adjacent pages. Core turns the seam results into page
groups. Implement optional `splitEager()` when the whole bundle can be classified in one
request.

## Test PDF loaders and rasterizers

The suites need PDFKit for generated inputs and Vitest 3 or newer to register tests. Also
install the engine for the adapter under test.

```sh
npm install --save-dev docture pdfkit vitest
```

```ts
import { describeLoaderConformance, describeRasterizerConformance } from "docture/testing/conformance";

describeLoaderConformance({
  name: "AcmePdfLoader",
  create: () => new AcmePdfLoader(),
  skip: { geometry: true, images: true },
});
```

`describeLoaderConformance()` passes generated PDF invoices to the loader by default and
checks media type acceptance, text, page numbering, optional geometry and images, aborts,
instance reuse, and disposal. Pass `fixtures: textFixtures` or `fixtures: pngFixtures` for
a plain-text or PNG loader. For another media type, such as the CSV loader above, pass
your own `ConformanceFixtures` profile with seeded documents in the type it accepts:

```ts
import { describeLoaderConformance, type ConformanceFixtures } from "docture/testing/conformance";

const csvFixtures: ConformanceFixtures = {
  mimeType: "text/csv",
  dimensions: false,
  async document(seed) {
    const text = `invoice,total\nINV-${seed},${seed * 10}`;
    return { bytes: new TextEncoder().encode(text), mimeType: "text/csv", expectedText: [`INV-${seed}`] };
  },
};

describeLoaderConformance({ name: "csv", create: () => csvLoader, fixtures: csvFixtures });
```

Checks the profile has no document for, such as scanned pages or invalid input, are
reported as skipped.

`describeRasterizerConformance()` renders the same PDF profile by default. Its `format`
option selects an advertised output format to check. Use skip flags only for optional
behavior a loader does not claim.
