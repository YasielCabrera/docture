Each example keeps its input documents beside the code. PDF examples use bundled invoices or bank statements, so no corpus download is needed. DOCX, email, and Docling examples keep their native input formats.

From a repository clone, install the workspace and run an example:

```sh
pnpm install
pnpm --filter @docture/examples quick-start
```

For a guided first run, follow [your first extraction](/docs/extraction/quick-start).

The examples workspace installs the optional development engines. Model and remote service examples document their configuration in the folder README. OCR engines may download model files on their first run.

Run the local examples and verification from the repository root:

```sh
pnpm --filter @docture/examples offline
pnpm --filter @docture/examples test
pnpm --filter @docture/examples typecheck
```

The offline command excludes provider calls, remote services, and OCR model downloads. Read the [examples README](https://github.com/YasielCabrera/docture/tree/main/apps/examples) for commands, document sources, and prerequisites.
