title: Runnable examples
description: Choose a complete program and check its prerequisites before running it.
---

The examples workspace installs the optional development engines. Each folder contains a complete program, a command, prerequisites, and expected behavior.

```sh
pnpm install
pnpm --filter @docture/examples run fetch
pnpm --filter @docture/examples quick-start
```

No key in Needs means no provider key. A superscript 1 marks a partial keyless path; superscript 2 refers to keyless CLI extraction through that folder's config. OCR may require opt-in model downloads.

```sh
pnpm --filter @docture/examples offline
pnpm --filter @docture/examples test
pnpm --filter @docture/examples typecheck
```

The offline tour avoids model calls and OCR model downloads; the loaders example still makes a URL-source HTTP request. For the full prerequisites and corpus provenance, read the [examples README](https://github.com/YasielCabrera/docture/tree/main/apps/examples).
