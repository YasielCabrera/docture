Each section names a symptom, explains its cause, and gives the fix. For every error code and its fields, see the [error reference](/docs/resources/errors).

## A local path fails after switching to the portable entry

The portable root rejects paths and file URLs with `UNSUPPORTED_SOURCE`. Import the local-file constructors or `resolveNodeSource` from `docture/node`. Bytes, HTTP URLs and loaded sources remain portable. See [Node file sources](/docs/getting-started/reference/node) and [source errors](/docs/resources/errors).

## An adapter imports but its first load reports a missing engine

Optional engines load when selected. Install the engine beside the application using the exact recipe for that entry. `MissingEngineError` names the package, range and entry. Import success does not prove that its engine is installed. See [installation](/docs/getting-started/installation) and [the error reference](/docs/resources/errors).

## Extraction says no strategy is eligible

Read the missing document facts in `NO_ELIGIBLE_STRATEGY`. A loader's advertised capability is an upper bound. Loaded pages can still lack positioned lines, and an ordinary short text can fall below the text-layer heuristic. Nonblank native elements and table cells also count as text. See [strategies](/docs/extraction/strategies) and [routing and fallback](/docs/extraction/routing).

## A scan or mixed PDF produces incomplete text

Select an OCR loader explicitly. For mixed pages, `withOcrFallback` evaluates only caller-selected low-quality pages and preserves intentional blanks. An OCR failure keeps the original page and records a warning. See [selected-page OCR](/docs/integrations/selected-page-ocr) and [scanned documents](/docs/integrations/scanned-documents).

## OCR uses memory for pages outside the intended limit

The built-in OCR loaders forward `maxPages` before rasterization. A custom rasterizer can ignore that hint, so check its implementation before you rely on the same bound. Capped loads omit total `pageCount` when it cannot be established. See [performance](/docs/extraction/performance) and [rasterizers](/docs/integrations/rasterizers).

## A selected page fails or output page numbers look unexpected

Pages are one-based and retain original document numbers. `convert --pages 2,4` selects those original pages. Invalid lists fail before loading config. A page outside a source or render cap produces `PAGE_OUT_OF_RANGE`. See [document conversion](/docs/conversion/quick-start) and [the error reference](/docs/resources/errors).

## Citations show text but cannot highlight printed lines

Stored Paperless content has no physical page boundaries or coordinates. Docling elements and cells retain their actual evidence granularity. Physical native boxes require bound original bytes and matching images; the review rejects a mismatched digest. See [Docling import](/docs/integrations/docling-import), [Paperless sources](/docs/integrations/paperless-read), and [the CLI guide](/docs/cli/quick-start).

## A Paperless apply skips a value or reports partial progress

Apply re-reads current values and skips fields another writer filled. Zero and false are present values. Tags are additive, and an existing extraction marker suppresses another audit note. Preserve the returned per-operation outcomes. A timeout or error response can follow a successful native write, so reconciliation checks actual state. See [Paperless write-back](/docs/integrations/paperless-updates).

## A Paperless apply tool is missing from MCP

The default server exposes the plan, read, and extract operations. Apply requires `paperless.enableApply` in caller config and is checked again when called. Tool arguments cannot enable it or replace credentials and mappings. See [the CLI API](/docs/cli/reference/cli).

## The HTTP service refuses a remote bind or an upload

Non-loopback binding requires a configured bearer token. Requests accept bounded JSON containing canonical base64 bytes and configured schema names. The service rejects paths, unknown keys, and model or config overrides. See [HTTP service](/docs/cli/http-service).

## A batch rejects its concurrency setting

Batch concurrency must be a finite positive integer. Fractions, zero, negative numbers, `NaN`, and `Infinity` fail before any source is processed. The rule applies to extraction and conversion batches. See [batches and lifecycle](/docs/extraction/batches).

## A calibration report has no supported threshold

The labelled sample may not meet the requested empirical precision and minimum support at a complete confidence tie. Missing or uncited OCR confidence stays unknown. The report does not apply a policy, and reordered `--align-by` evidence is rejected. See [measuring accuracy](/docs/evaluation/quick-start).
